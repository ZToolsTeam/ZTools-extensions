# @ztools/declarative-ui

Compile-time and test-time SDK (TypeScript declarations and runtime) for ZTools plugins. Auto-generated — do not edit manually. At runtime, the ZTools desktop client provides the runtime. Import primitives via `import { List, Action } from "@ztools/declarative-ui"`.

插件编译与测试用的 SDK（类型声明与运行时），自动生成，请勿手改。用户安装插件后，运行时由 ZTools 客户端提供。插件统一 `import { List, Action } from "@ztools/declarative-ui"`。

- API & permissions / 组件、系统 API 与权限说明：[docs/en/api.md](../../docs/en/api.md) · [docs/api.md](../../docs/api.md)
- Exact type signatures / 准确的类型签名以 `dist/*.d.ts` 为准。
