# 容器管控

查看本机 Docker 容器的状态、端口映射和 CPU / 内存采样，启动、停止、重启容器，读取最近 100 行日志，并在确认清单后清理已停止的容器。

## 使用

- 命令：查看本地所有 Docker 容器状态、端口映射与实时日志（关键词如 `docker`、`容器`）；另有"筛选运行中的容器并读取 CPU、内存采样""列出已停止容器，确认清单后清理，保留挂载的数据卷"两个命令，打开时分别预先筛选运行中和已停止的容器。
- 选中容器：运行中且映射了常见网页端口（80、443、3000、8080 等）时 `Enter` 在浏览器打开对应的本机地址，否则 `Enter` 查看日志；`⌘/Ctrl+Enter` 启动或停止容器；`⌘/Ctrl+K` 中还有查看日志、重启容器、复制完整容器 ID。
- 资源数字是刷新时的一次采样；读取失败时显示原因，不以零值代替。日志按标准输出和标准错误输出分开显示。
- "清理停止容器"先列出待删清单，确认后逐个删除已停止的容器（一次最多 100 个），不删除镜像、挂载的数据卷和宿主目录；容器可写层会永久删除，请先另存需要保留的数据。
- 操作进行中可点"取消"。操作失败、取消或超时后会重新读取容器列表显示实际状态，不能确认的操作不会报成功。
- 需要已安装并启动 Docker Desktop（macOS 上也可以用提供 Docker 命令行与本机连接的 Colima 或 OrbStack）。插件使用 Docker 当前上下文，不修改 Docker 配置；远程 TCP / SSH 上下文需要先在 Docker 中切换为本机上下文。

## 平台与要求

- 支持：Windows、macOS
- 需要客户端 1.1.8.5 或更新。

## 网络与数据

- 插件不访问互联网：通过本机 Docker 命令行连接本机 Docker 引擎（Unix 套接字或 Windows 命名管道）。
- "打开服务网页"只是在浏览器中打开容器映射到本机的地址，例如 `http://localhost:8080`。
