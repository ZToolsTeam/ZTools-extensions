# AI文档转Word

在本机把 Markdown 文本或文件转换为 Word（.docx）新副本，或复制为可粘贴到 Word、WPS 的富文本。

## 使用

- 命令：`md转word`、`markdown转word`、`导出word`；`复制为word格式` 读取剪贴板后直接按默认的公文风格复制富文本。
- 打开时读取剪贴板；也可点顶部「打开文件」选择 UTF-8 编码的 `.md`、`.markdown`、`.txt` 文件，或在动作面板选择「编辑 Markdown」。单篇最多 256 KiB。
- 左侧选择排版风格（公文风格、商务报告、学术三线表）、正文字号和首行缩进。
- 选中文档后 Enter 另存 `.docx` 新副本，⌘/Ctrl+Enter 复制为富文本；⌘/Ctrl+K 里还有编辑 Markdown、复制 Markdown 原文。
- 支持标题、加粗、斜体、删除线、列表、表格、链接和代码块。图片只保留说明和地址，不下载图片，也不读取引用的本地文件；原始 HTML 按文字保留；代码块保留等宽排版和换行，不提供语法高亮。
- 另存为 .docx 文件：选择已有文件时，只有在系统保存窗口里确认替换后才会覆盖它；取消保存不会生成文件。转换中有无法保留的内容、写入或剪贴板确认失败都会显示错误。
- 实际字体由打开文档的设备决定；公文风格是排版预设，不代表文档符合某项正式标准。

## 平台与要求

- 支持：Windows、macOS
- 需要客户端 1.1.8.5 或更新。

## 网络与数据

- 不联网，数据只保存在本机。
