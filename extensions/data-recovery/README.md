# 数据恢复

开发中，暂不在插件市场提供：客户端目前只能列出 C、D、E 盘回收站里的文件，且只给出回收站内部的 $R 文件名，没有原始文件名、原路径和删除时间，用户难以辨认要找回的文件；也不能扫描已清空回收站、格式化或被覆盖的数据。等客户端能读出回收站文件的原始名称与路径、提供磁盘级的已删除文件扫描能力，并在 Windows 上实测通过后再发布。

列出 Windows 回收站里的文件，把勾选的文件复制到桌面的 ZToolsRecovered 文件夹。

## 使用

- 命令：在启动框搜索“数据恢复”打开。
- 扫描 C、D、E 盘回收站里的文件（每个用户的回收站只读取前 120 个条目，总共最多列出 200 个文件；回收站里被删除的文件夹不会列出），按扩展名分为文档、图片、视频音频、压缩包与代码、其他，可勾选；打开时不勾选任何文件。
- 列表显示的是回收站内部的文件名（以 `$R` 开头，保留扩展名）和文件的修改时间，不显示原始文件名、原路径和删除时间，恢复出来的文件也使用这个名字。
- Enter：把勾选的文件复制到桌面 ZToolsRecovered 文件夹里本次新建的、以时间命名的子文件夹（没有勾选时只提示，不做处理）；Ctrl+Enter：在资源管理器中定位该文件；Ctrl+K 里可打开恢复文件夹。恢复结果和失败原因显示在状态栏和提示里。
- 回收站里的文件保持不动；每次恢复都放进新的子文件夹，不会覆盖已有文件，同名文件自动加序号。
- 只能取回仍在回收站里的文件，不能恢复已清空回收站、格式化或被覆盖的数据。

## 平台与要求

- 支持：仅 Windows

## 网络与数据

- 不联网，数据只保存在本机。
