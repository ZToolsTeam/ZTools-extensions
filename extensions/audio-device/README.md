# 音频设备切换

查看 macOS 的音频输出与输入设备，切换系统默认设备，调节设备音量和静音。

## 使用

- 命令：在启动框输入“音频”“耳机”打开设备列表；输入“麦克风”打开时只显示输入设备；输入“静音”直接切换当前默认输出设备的静音状态（无界面，“取消静音”同样是切换）。
- 顶部下拉框可筛选全部设备、输出设备、输入设备或常用设备；搜索框可按设备名或连接方式（如“蓝牙”“USB”“HDMI”）查找。
- Enter：把选中设备设为系统默认输出或输入；⌘K：打开动作面板，可静音 / 取消静音、设置音量（0–100）、音量增减 10%、设为常用、查看设备信息。
- 设备不支持设为默认、软件音量或静音时，不显示对应动作；已经是默认的设备不再显示“设为默认”，回车直接静音 / 取消静音（不支持静音时为设置音量）。
- 每次切换、调音量、静音后都会读回系统状态核对，未生效时提示失败原因，例如“系统未切换到所选设备”“设备音量未达到请求值”。

## 平台与要求

- 支持：仅 macOS
- 需要客户端 1.1.8.5 或更新。
- 读写音频设备依赖客户端自带的 macOS 音频组件；组件不可用时列表显示“无法读取音频设备”及原因。

## 网络与数据

- 不联网，“常用设备”记录只保存在本机。
