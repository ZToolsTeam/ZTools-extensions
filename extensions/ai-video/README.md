# AI 视频增强

列出“视频”“下载”“桌面”文件夹里的视频，把勾选的视频交给客户端重新编码为 mp4。目前客户端只用 ffmpeg 做普通转码，界面上列出的补帧、超分、降噪模型都不会执行。

## 使用

- 命令：在启动框搜索“AI 视频增强”打开。
- 列表列出这三个文件夹（含子文件夹）里的 mp4、mkv、mov、avi、flv、webm、wmv、ts、m4v 文件：每个文件夹只从扫描到的较大文件里挑选，最多 40 个，不保证列全。列表按体积从大到小排列，扫描后默认全部勾选。
- Enter：确认后处理全部勾选的视频；Ctrl+Enter：在资源管理器中定位文件；Ctrl+K：打开动作面板，可只处理当前视频。
- 输出文件名为 `<原文件名>_processed.mp4`，保存在扫描到该视频的那个文件夹（“视频”“下载”或“桌面”）的第一层；原文件不改动。
- 已存在的同名输出文件会被覆盖，转换失败时会被删除。
- 界面上选择的模型、目标帧率、目标分辨率、编码器和“场景切换防伪影保护”目前都不生效。
- 需要自行安装 ffmpeg，并能在命令行直接运行；找不到 ffmpeg 时提示“本机未检测到 ffmpeg”。单个文件转换超过 60 秒会中止并报错。

## 平台与要求

- 支持：仅 Windows

## 网络与数据

- 不联网，数据只保存在本机。
