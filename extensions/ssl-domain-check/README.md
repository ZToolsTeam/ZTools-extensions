# 域名与SSL诊断

查询域名 HTTPS（443 端口）证书的信任状态、域名匹配、有效期和证书链，并查看该域名的 DNS 记录。

## 使用

- 命令：`ssl`（也可输入 `cert`、`dns`、`证书检测`、`域名诊断`）
- 在搜索框输入域名或网址（如 `example.com`），按 Enter 查询；只查询 443 端口，网址里带其他端口时会提示移除。
- 证书结果显示信任验证、域名匹配、TLS 协议、生效与到期时间、颁发机构、备用名称、SHA-256 指纹和证书链（最多显示 8 项）；剩余 14 天以内标为"即将到期"。选中证书按 Enter 复制诊断摘要。
- DNS 记录查询 A、AAAA、CNAME、MX、TXT，可在顶部下拉框按类型筛选，选中记录按 Enter 复制记录值。
- 证书与 DNS 分别查询，一项失败时另一项照常显示，并提示失败原因；查询中可以取消。

## 平台与要求

- 支持：Windows、macOS
- 需要客户端 1.1.8.5 或更新。

## 网络与数据

- 证书：由客户端直接连接你输入域名的 443 端口读取证书。
- DNS：向 Cloudflare 的 DNS over HTTPS 服务（`cloudflare-dns.com`）查询，会把你输入的域名发送给该服务。
- 不保存查询记录。
