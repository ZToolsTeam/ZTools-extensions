# 下载管理

汇总系统下载目录、自动识别到的网盘 / 下载器 / 办公软件接收目录和你添加的目录中的文件，支持筛选、打开、定位、复制和移入回收站。

## 使用

- 命令：下载管理（关键词如 `下载`、`downloads`）、网盘下载、办公软件接收文件（`微信文件`、`QQ文件` 等）、清理安装包；后三个命令打开后分别预先筛选网盘与下载器、办公软件接收目录、安装包。
- 列表按今天、近 7 天、更早分组（筛选安装包时改为按体积从大到小排列）；搜索框旁的下拉框可按来源（办公软件、网盘与下载器、浏览器与系统下载、自定义目录）或文件类型筛选。
- `Enter` 打开文件，`⌘/Ctrl+Enter` 在文件管理器中定位，`⌘/Ctrl+Shift+C` 复制文件本身，`⌘/Ctrl+P` 置顶保护，`⌘/Ctrl+Backspace` 移入回收站（需确认），`⌘/Ctrl+R` 刷新，`⌘/Ctrl+K` 打开动作面板。
- 未自动识别的目录可在动作面板「添加/管理自定义下载监控目录」中通过系统窗口选择添加；移除目录配置不会删除文件。
- 打开插件时扫描一次，目录变化后需刷新。每个目录最多列出 100 个文件，超出上限或扫描不完整时摘要标注“仅部分结果”，读取失败的目录单独列出，这时列表不能当作完整记录。
- 批量清理（动作面板）：清理当前列表里的安装包，或 30 天前且不小于 100 MB 的文件。只处理当前筛选结果中未置顶保护的文件，执行前列出全部路径并确认；修改时间未知的文件不参与按时间清理。关闭插件会停止尚未发出的回收请求。
- 文件移入系统回收站，不会立即释放磁盘空间；只有确认移入成功的文件才从列表移除，失败项保留并提示。

## 平台与要求

- 支持：Windows、macOS
- 客户端已内置，无需单独安装。

## 网络与数据

- 不联网，数据只保存在本机；置顶保护与自定义目录保存在插件存储中，保存失败会提示，不会显示为成功。
