# 定时关机

列出几种预设的电源动作：10、30、60、120 分钟后关机，立即锁屏，立即睡眠，以及复制取消关机计划的命令。

## 使用

- 命令：`定时关机`（也可输入 `自动关机`、`shutdown`）、`锁屏`、`睡眠`、`取消关机`，都打开同一个列表。
- 定时关机：选中某个时长后按 `Enter`，确认后由客户端设定关机计划，提示预计关机时间。到时系统会关闭所有程序，未保存的内容可能丢失。`Ctrl+Enter` 复制等价的系统命令（如 `shutdown.exe /s /t 600`）。
- 已经设定过关机计划时，再次设定会失败并提示原因，需要先取消原来的计划。
- 立即锁屏、立即睡眠：按 `Enter` 直接执行，不再确认。
- 取消关机计划：客户端不提供取消接口，插件不能直接取消。在"取消已设定的关机计划"上按 `Enter` 复制 `shutdown.exe /a`，粘贴到命令提示符中运行即可取消。
- 只有固定的预设时长，不能自定义倒计时或指定时刻，也没有定时重启。
- 执行失败时提示客户端返回的原因，不会报成功。

## 平台与要求

- 支持：仅 Windows

## 网络与数据

- 不联网，不保存数据。
