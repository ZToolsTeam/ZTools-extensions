# 键盘清洁锁

擦拭键盘时临时拦截键盘输入，可选同时拦截鼠标；倒计时结束、紧急解锁或与客户端失联时自动恢复。

## 使用

- 命令：锁定键盘输入以便擦拭清洁键盘，倒计时结束自动恢复输入（关键词如 `清洁键盘`、`锁键盘`）。
- 选择 15 秒、30 秒、1 分钟、2 分钟或 5 分钟后按 `Enter` 开始；`⌘+Enter` 自定义 5～300 秒。只有系统确认输入拦截已启用，才显示"已锁定"。
- 默认只锁键盘，可在搜索框右侧改为"键盘与鼠标"，同时拦截鼠标移动、点击和滚动。
- 随时按 `⌘+U`（或 `Control+U`）紧急解除；只锁键盘时也可以用鼠标点击"立即解除"。倒计时结束、离开插件、客户端退出或通信中断都会解除。
- 需要在"系统设置 → 隐私与安全性 → 辅助功能"中允许 ZTools。没有权限或处于安全输入状态时会明确失败，不会假报锁定。
- 电源键、Touch ID、系统保留按键、媒体键和部分触控板手势不在拦截范围。任何人按紧急组合键都能解除，所以它不是系统锁屏，不能用来防止他人使用电脑。
- 只统计本次拦截次数，不记录按键内容，不保存使用历史。

## 平台与要求

- 支持：仅 macOS
- 需要客户端 1.1.8.5 或更新。

## 网络与数据

- 不联网，数据只保存在本机。
