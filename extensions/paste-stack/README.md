# 纯文本与粘贴栈

把粘贴栈页面打开期间连续复制的多段文本依次放进粘贴栈，按先进先出或后进先出顺序列出，选中一条即可粘贴回原输入位置；另有一个命令把剪贴板里的富文本转成纯文本。

## 使用

- 命令：`粘贴栈`（也可输入 `连续复制粘贴`、`paste stack`）；直接按顺序打开：`顺序粘贴模式`（先进先出）、`倒序粘贴模式`（后进先出）；清除格式：`清除格式`、`纯文本粘贴`
- 只在粘贴栈页面打开期间监听剪贴板，只记录文本；与队列最后一条相同的内容不会重复入栈。顶部可暂停或开启监听、清空队列。
- 选中条目按 Enter 发送到原输入位置，该条移入"已发送"，在顶部下拉框切到"已发送（可恢复）"可恢复回队列；⌘/Ctrl+Enter 只复制该条；⌘/Ctrl+K 里可上移、下移或移除。
- "清除格式"读取剪贴板文本后重新写回，只去掉富文本格式，文字内容不变；剪贴板里没有文本时提示失败。
- 待发送与已发送合计最多 500 条（或 8 MiB）。
- macOS 上自动粘贴需要在"系统设置 > 隐私与安全性 > 辅助功能"中授权 ZTools；未授权时提示粘贴失败，条目保留在队列中。

## 平台与要求

- 支持：Windows、macOS
- 需要客户端 1.1.8.3 或更新。

## 网络与数据

- 不联网，数据只保存在本机。
