# 进程监控

查看本机进程的 CPU 与内存占用，查询端口被哪个进程占用，并可结束进程或定位程序文件。

## 使用

- 命令：`进程监控`（也可输入 `结束进程`、`任务管理器`）；查端口：`端口占用`、`查端口`、`port`。在搜索框输入 `port:8080` 也能查询指定端口。
- 列表默认每 2 秒刷新一次，顶部可暂停自动刷新或手动刷新（⌘/Ctrl+R）；下拉框可切换按内存、CPU、名称、PID 排序，或只看高负载进程、系统服务、用户应用、本地端口占用。
- 选中进程按 Enter 结束进程，⌘/Ctrl+Enter 强制结束进程树，执行前都会确认；⌘/Ctrl+K 里还有平缓关闭、定位文件目录（⌘/Ctrl+O）、复制 PID（⌘/Ctrl+C）、复制可执行路径（⌘/Ctrl+Shift+C）、复制启动命令行（系统没有提供命令行时提示读取不到）、查看数字签名与托管服务（⌘/Ctrl+I）。
- 系统内核与会话管理等关键进程会被拦截，不能结束；macOS 上结束程序坞、访达等系统界面进程前会额外警告。平缓关闭没有响应时，需要再次确认才会强制结束。
- 结束失败（如权限不足）时提示失败原因。

## 平台与要求

- 支持：Windows、macOS

## 网络与数据

- 不联网，不保存数据。
