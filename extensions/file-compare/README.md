# 文本对比

逐行对比两段文本、代码或配置文件，列出每一处改动，可复制 unified diff 格式的差异报告。

## 使用

- 命令：文本对比（关键词如 `diff`、`对比`）。
- 左侧（原文）和右侧（新文）可以在编辑框里粘贴，也可以分别用剪贴板内容或选择文件（UTF-8 文本，单个不超过 4 MB）；只载入一侧时会提示补上另一侧。
- 两侧都有内容后逐条列出差异，右侧预览显示该处的增删行，标题显示删除、新增的行数和差异处数。
- 开始时选中第一行按 `Enter` 打开编辑框，编辑框里 `⌘/Ctrl+Enter` 开始对比；有差异时 `Enter` 复制完整差异报告，`⌘/Ctrl+Enter` 复制当前这一处，`⌘/Ctrl+K` 打开动作面板（交换左右、忽略空白差异、换用剪贴板或文件、清空等）。
- “忽略空白差异”会把连续空白视为一个空格、去掉行首尾空白后再比较。
- 每侧最多 20000 行；改动过多时按近似结果显示，并在标题中注明。

## 平台与要求

- 支持：Windows、macOS
- 客户端已内置，无需单独安装。

## 网络与数据

- 不联网，数据只保存在本机。
