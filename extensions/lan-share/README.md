# 局域网传文件

选择电脑上的文件加入共享，启动客户端的局域网共享服务后，同一网络的手机或电脑用浏览器打开本机地址（或扫描二维码）即可下载这些文件。

## 使用

- 命令：局域网传文件。
- 第一行是共享服务：未运行时按 `Enter` 启动；运行中时右侧显示访问地址和二维码，`Enter` 复制访问地址，`Ctrl+Enter` 停止服务。打开插件只读取状态，不会自动启动服务。
- 顶部"选择文件并共享"弹出文件选择框，可多选；选中的文件加入共享列表，服务未运行时会同时启动。读不到的文件会提示已跳过。顶部"刷新"重新读取状态。
- 其余各行是共享列表里的文件，右侧显示下载地址和二维码。`Enter` 复制下载地址（服务运行且该文件正在共享时才有），`Ctrl+Enter` 暂停或恢复共享该文件，`Ctrl+K` 里可以把文件从共享列表移除（只移出列表，不删除文件）。
- 如果手机打不开地址，服务那一行的右侧会列出本机的其他地址，可以换用与手机同一网络的那个。
- 首次启动服务时 Windows 防火墙可能询问是否允许 ZTools 访问网络，需要允许，其他设备才能连上。
- 当前版本的限制：共享网页只提供文件下载，不支持从手机上传；不能共享剪贴板文本；共享网页不能下载文件夹。

## 平台与要求

- 支持：仅 Windows

## 网络与数据

- 插件只向客户端查询和修改共享状态，不访问外部网络。
- 客户端的共享服务运行时在本机所有网卡上提供 HTTP 访问，不需要访问密码，同一网络内的设备都能打开共享列表并下载其中的文件。关闭插件后服务仍在运行，直到在插件里停止服务或退出 ZTools，不用时请停止服务。
