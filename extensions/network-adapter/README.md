# 网卡管理

查看本机网卡的 IPv4 地址、子网掩码、MAC 地址、网关、DNS 与连接状态，可刷新 DNS 缓存，或把网卡 DNS 设为 223.5.5.5、恢复自动获取。

## 使用

- 命令：网卡管理（插件主命令）。
- 搜索栏右侧可筛选全部、物理网卡、虚拟与回环网卡、仅已连接接口；可按名称、IP、MAC、DNS 搜索。
- 有 IPv4 和 MAC 地址时，`Enter` 复制 IPv4 地址，`Ctrl+Enter` 复制 MAC 地址；缺少哪项就不提供哪项的复制动作，后面的动作依次前移。`Ctrl+C` 复制单行摘要；`Ctrl+Shift+C` 复制完整配置 JSON；`Ctrl+K` 打开动作面板。
- `Ctrl+P` 把当前网卡的 DNS 设为 223.5.5.5（阿里公共 DNS，替换现有 DNS）；`Ctrl+Shift+D` 恢复自动获取 DNS。不设置备用 DNS；回环网卡不提供这两项。
- 修改 DNS 需要以管理员身份运行 ZTools，否则提示失败。
- 顶部「刷新DNS缓存」清空本机 DNS 解析缓存，「刷新网卡」重新读取网卡信息。
- 读取网卡失败时显示失败原因；读不到的 MAC 地址、子网掩码显示「未识别」。

## 平台与要求

- 支持：仅 Windows
- Windows 实现尚待真机复核。

## 网络与数据

- 不联网，数据只保存在本机。
- 把 DNS 设为 223.5.5.5 后，该网卡的域名解析请求会发往阿里公共 DNS。
