# PDF 工具箱

开发中，暂不在插件市场提供：客户端缺少可靠的 PDF 解析、渲染与生成组件：现有的 PDF 重建方式会把字体、图片等数据当成页面内容写入，合并、拆分、压缩输出的文件内容错乱，已停用；PDF 与 Word/Excel/PPT/图片互转、加密解密没有对应组件。目前只能导出未压缩 PDF 中的简单文字。待客户端提供可靠的 PDF 解析、渲染与生成能力后，恢复对应工具并去掉草稿。

提取 PDF 中未压缩的文字，导出为 TXT 或 HTML 文件。合并、拆分、压缩、格式互转、加解密暂不可用。

## 使用

- 命令：PDF 工具箱（插件主命令）。
- 打开后扫描文档、下载、桌面目录里的 PDF（每个目录最多列出 40 个）；搜索栏右侧选择导出 TXT 或导出 HTML。
- `Enter` 导出已勾选的 PDF（没有勾选时导出当前 PDF）；`Ctrl+K` 打开动作面板，可只导出当前 PDF、用默认程序打开 PDF、在文件夹中显示 PDF 或上次的输出文件。
- 输出到 PDF 所在目录，文件名为 `原名.txt` 或 `原名.html`，已存在时依次改为 `原名 (1).txt` 等；无法确认同名文件是否存在时停止导出，不覆盖已有文件。
- 只能读取未压缩的简单文字，结果可能不完整；扫描件和多数压缩的 PDF 会提示无法提取。提取结果是空白或疑似乱码时按失败提示，并给出已生成的输出文件路径。
- HTML 是只含文字的纯文本网页，不保留版式与图片。
