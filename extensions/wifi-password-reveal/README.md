# Wi-Fi 密码查看

查看本机已保存的无线网络，按需读取密码，并生成手机连网二维码。

## 使用

- 命令：查看本机保存的所有 Wi-Fi 密码并生成手机扫码连网二维码（关键词如 `wifi`、`Wi-Fi密码`、`wlan`）。
- 列表只显示网络名称和加密类型，不预先读取密码。选中网络按 `Enter` 复制密码，`⌘/Ctrl+Enter` 查看密码与连网二维码，`⌘/Ctrl+K` 中可复制网络名称；开放网络和企业认证网络按 `Enter` 直接查看详情。
- 系统没有提供加密类型时，生成二维码前要按路由器设置选择加密类型；选择开放网络不会读取密码。企业认证网络没有可共享的密码，不生成二维码。
- 搜索框右侧可筛选当前连接、开放网络、企业认证；系统没有提供当前连接信息时（新版 macOS 的命令行接口通常不返回当前网络）不显示“当前连接”标注和筛选。
- 读取失败、授权取消或系统没有提供密码时，界面显示实际原因，不会显示占位数据。

## 平台与要求

- 支持：Windows、macOS
- 需要客户端 1.1.8.5 或更新。
- macOS：通过系统钥匙串读取已保存网络的密码，读取密码时由系统弹窗请求授权。系统不提供已保存网络的加密类型，生成二维码前需要手动选择。
- Windows：通过系统自带的无线网络配置导出能力读取已保存网络；读取明文密码可能需要以管理员身份运行客户端。在不同系统语言、代码页与网卡环境下的表现可能有差异；当前连接状态无法确定时不会标注"当前连接"。
- Windows 实现尚待真机复核。

## 网络与数据

- 插件不发起网络请求；读取到的密码只在界面中显示，或按你的操作复制到剪贴板，不会保存。
