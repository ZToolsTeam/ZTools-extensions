# 办公文档瘦身

在本机重新压缩 Word、PPT、Excel 文档（docx、pptx、xlsx），保留图片原字节；可移除作者属性与批注，或把文档里的原图导出为 ZIP。只另存新副本，不修改原文件。

## 使用

- 命令：文档瘦身（关键词如 `ppt压缩`、`word压缩`）、清除文档隐私（`擦除作者信息`、`删除批注痕迹`）、提取文档图片（`提取ppt图片`、`导出word图片`）。前两个打开同一个处理界面，第三个用于导出原图。
- 点“选择文档”选取文件，列表显示大小、原图数量、是否含作者属性和批注；`Enter` 开始处理并选择新副本的保存位置。
- 处理时按最高压缩级别重新打包文档结构，图片不重新编码，所以处理后不一定更小。
- “移除作者属性与批注”（默认开启）删除文档属性里的作者、最后修改者、修订号，以及批注和正文中的批注标记；不处理正文里的个人信息，修订内容保留。
- 导出原图时把文档内的图片按序号命名打包为 ZIP；文档里没有图片时提示无法导出。
- 新副本须与原文档同格式（导出原图为 .zip），不能覆盖原文件；选择其他已有文件时，只有在系统保存窗口里确认替换后才会覆盖它；单个文档最大 16 MiB；保存前会回读校验压缩包内容。

## 平台与要求

- 支持：Windows、macOS
- 需要客户端 1.1.8.5 或更新。

## 网络与数据

- 不联网，数据只保存在本机。
