# 最近项目

在 ZTools 中搜索“最近项目”，集中查看编辑器最近打开的本地文件夹与工作区。

- `Enter`：使用记录对应的编辑器打开项目。
- `⌘/Ctrl+Enter`：“在终端打开”当前文件夹；工作区文件使用其所在目录。
- 动作面板：复制项目路径或 Git 分支。
- 顶部下拉框：筛选 VS Code 家族或 JetBrains；搜索支持名称、路径、编辑器与分支。
- “隐藏失效项目”只改变当前列表，可随时恢复显示，不删除编辑器记录或项目文件。

## macOS

读取 VS Code、VS Code Insiders、Cursor、Trae、Windsurf 与 JetBrains 在默认配置位置保存的本地历史。支持 VS Code 家族的 SQLite 最近项目记录及新版共享历史库、JetBrains 的 `recentProjects.xml`。自定义 `--user-data-dir` 配置不自动扫描。

最近的单个文件不作为项目列出；远程项目不使用本地路径打开，扫描后会显示跳过的数量。未保存打开时间的历史不显示虚构的“刚刚打开”。Git 分支读取包含工作树与项目子目录。

读取失败会显示来源与原因，不当成没有项目。打开时会检查路径与对应编辑器：路径已移除、编辑器未安装或系统拒绝打开都会提示失败。编辑器收到请求后仍可能需要自行处理项目加载或信任提示。

扫描和打开都可取消；已经启动的编辑器或终端窗口不会被强行关闭。

## Windows

读取的编辑器与历史格式与 macOS 相同：编辑器配置在 `%APPDATA%` 下（JetBrains 为 `%APPDATA%\JetBrains`），新版共享历史库在用户目录下。打开项目时在常见安装位置（`%LOCALAPPDATA%\Programs`、Program Files 及其中的 JetBrains 目录）查找编辑器程序并直接启动，不经过命令行解释器；找不到时提示未找到安装位置。“在终端打开”启动系统命令提示符，以项目目录为工作目录；网络共享路径会临时映射盘符，路径含 `& | < > ^ % !` 时拒绝打开。

## 平台与要求

- 支持：Windows、macOS
- 需要客户端 1.1.8.5 或更新。
- Windows 实现尚待真机复核。
