# 防盗水印

选择 JPG、PNG 或静态 WebP 原图，按 ⌘/Ctrl+K，在动作面板选择“修改水印用途”填写用途，保存后选择文字模板。按 Enter 另存 PNG 新副本，⌘/Ctrl+Enter 复制加水印图片。图片只在本机处理，原图保持不变：保存时选中原图会被拒绝；选择其他已有文件时，只有在系统保存窗口里确认替换后才会覆盖它。

“快速加水印”入口先读取剪贴板图片，确认文字后按 Enter 复制结果。也可在普通入口点击“读取剪贴板”。文字模板中的用途和日期按当前填写的用途和当天日期生成。

输入及输出最多 16 MiB；边长最多 8192 像素，总计最多 8 × 1024 × 1024 像素。输出保留解码后的原图尺寸（包括 JPEG 拍摄方向），统一为 PNG。无法解码、生成或写入时会明确报错，不生成空白替代图片。水印仅提供用途标记，不能保证图片无法被篡改或冒用。

## 平台与要求

- 支持：Windows、macOS
- 需要客户端 1.1.8.4 或更新。

## 网络与数据

- 不联网，数据只保存在本机。

## 开发验证

在插件仓库根目录执行 `node --test extensions/id-watermark/tests/*.test.mjs`，检查真实声明式运行时入口及失败边界；`extensions/id-watermark/tests/browser-watermark.mjs` 导出浏览器回归函数，需在具备 OffscreenCanvas 的隔离测试页面运行，覆盖实际编解码、原图像素保留、文件服务与动作链路。浏览器测试的文件适配器只能使用测试目录，剪贴板使用测试回执。
