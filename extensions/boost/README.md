# 开机启动项

列出占用内存最多的进程、“启动”文件夹里的开机启动项和临时文件夹里的文件，勾选并确认后可以结束进程，或把启动项快捷方式和临时文件移入回收站。

## 使用

- 命令：在启动框搜索“开机启动项”打开。
- 列表包括：内存占用最高的 30 个进程；当前用户和所有用户“启动”文件夹里的项目；名称属于常见自启软件（如 OneDrive、Steam、微信）的正在运行的进程；临时文件夹（`%TEMP%`）里的前 15 个文件。
- 标为“自启常驻”的进程只是按进程名或路径判断，插件不读取注册表、计划任务或系统服务里的自启设置，也不能禁用这些启动项；结束这类进程只影响本次运行，不会取消它的开机启动。
- 扫描完成后默认不勾选任何项目，需要自己勾选。部分内容读取失败（例如进程列表、内存占用）时，顶部状态条会显示原因。
- Enter：弹出确认框，写明会结束几个进程、移走几个文件，确认后只处理勾选的项目：“启动”文件夹里的项目和临时文件移入回收站，进程被强制结束（进程里未保存的内容会丢失）。没有勾选时不会执行；处理失败的项目会逐条提示原因，不会改为处理其他项目。
- Ctrl+Enter：在资源管理器中定位（读不到路径的进程没有这个动作，Ctrl+Enter 改为结束该进程，同样需确认）；Ctrl+K：打开动作面板，可单独结束某个进程（需确认）。
- 名为 System、csrss、lsass、svchost、wininit、explorer、dwm、ZTools 等的进程，客户端标为系统进程的进程，以及位于 `C:\Windows` 下的进程受保护，不能勾选或结束（“自启常驻”同样适用）。公共“启动”文件夹（`C:\ProgramData` 下）里的项目对所有用户生效，插件不能移除。

## 平台与要求

- 支持：仅 Windows

## 网络与数据

- 不联网，数据只保存在本机。
