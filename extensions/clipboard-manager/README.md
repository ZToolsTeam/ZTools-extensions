# 剪贴板历史

查看客户端在本机记录的剪贴板历史（文本、图片、文件），可以搜索、置顶、编辑，并粘贴回当前使用的应用。

## 使用

- 命令：在启动框搜索“剪贴板历史”打开。
- 列出最近 100 条记录，搜索框支持内容和拼音缩写，顶部下拉框按类型筛选（已置顶、颜色、JSON、代码、链接、文件、图片、纯文本）。
- Enter：粘贴到前台应用；⌘/Ctrl+Enter：只复制到剪贴板；⌘/Ctrl+K：打开动作面板。
- 常用快捷键：⌘/Ctrl+P 置顶或取消置顶；⌘/Ctrl+E 编辑；⌘/Ctrl+N 新建；⌘/Ctrl+D 查看完整详情；⌘/Ctrl+B 显示或隐藏右侧详情；⌘/Ctrl+O 打开链接或定位文件；⌘/Ctrl+Shift+V 按顺序粘贴下一条；⌘/Ctrl+X 删除（需确认）；⌘/Ctrl+Shift+X 清空所有未置顶记录。
- 清空未置顶记录（包括状态栏的“清空非置顶”）前会请你确认，置顶的记录会保留。
- 识别到疑似 API Key、GitHub 令牌、AWS 密钥、私钥、JWT 等敏感内容时，列表和预览里遮罩显示，复制和粘贴仍使用原文。
- 粘贴到前台应用需要模拟按键，macOS 上要在系统设置的“辅助功能”中给 ZTools 授权；未授权时内容只复制到剪贴板，不会自动粘贴，并提示去系统设置授权。

## 平台与要求

- 支持：Windows、macOS
- 需要客户端 1.1.8.3 或更新。

## 网络与数据

- 不联网，剪贴板历史只保存在本机。
