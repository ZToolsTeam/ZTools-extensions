# 微信清理

扫描微信电脑版的缓存、日志、聊天视频与图片、接收文件等，确认后把勾选的文件移入回收站；聊天记录数据库始终不在清理范围内。

## 使用

- 命令：微信清理（插件主命令）。
- 扫描位置：`文档\xwechat_files`、`文档\WeChat Files`、C 到 G 盘根目录下的 `WeChat Files` 与 `xwechat_files`、`%APPDATA%\Tencent\xwechat` 下的日志与缓存目录，以及微信输入法的日志目录。
- 左侧按类别查看：朋友圈与网页缓存、小程序组件包、运行日志（.xlog）、崩溃转储（.dmp）、表情包与资源缓存、升级补丁缓存、聊天视频与语音、聊天图片（.dat）、聊天接收文件。聊天视频与语音、聊天图片和接收文件默认不勾选：清理后聊天里的视频、语音和过期图片可能无法再查看，接收的文件会被移走。
- 搜索框右侧按微信账号筛选。
- 每个扫描目录最多取 150 个文件，右侧按体积从大到小最多显示 60 个，选左侧类别或搜索可以看到其它文件。表头复选框只勾选或取消当前显示出来的文件。
- `Enter` 清理已勾选的文件，确认框按类别列出文件数和大小，确认后移入回收站；`Ctrl+Enter` 在资源管理器中定位；`Ctrl+K` 中可勾选、用默认程序打开或复制路径。
- 扫描后只默认勾选右侧显示出来的、属于缓存、日志、崩溃转储、表情包、升级补丁、小程序这些类别的文件；没显示出来的文件不会被勾选。用途无法识别的文件归入“朋友圈与网页缓存”显示，标为“用途未识别”，也不默认勾选。清理范围是当前账号筛选下所有已勾选的文件。
- 左侧类别的体积包含没有列出的文件，只有列出并勾选的文件会被清理。文件移入回收站后仍占用磁盘空间，清空回收站后才会释放。
- 清理后的提示给出实际移入回收站的文件数；有文件没能移入回收站（例如正被微信占用）时，提示失败的数量和原因。
- 聊天记录与联系人数据库（`db_storage` 下的 .db、`MSG*.db`、`MicroMsg.db` 等）锁定显示，不能勾选，也不会被删除。

## 平台与要求

- 支持：仅 Windows

## 网络与数据

- 不联网，数据只保存在本机。
