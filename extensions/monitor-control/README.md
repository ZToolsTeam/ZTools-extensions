# 屏幕亮度与控制

搜索“亮度”打开显示器列表。Enter 增加当前显示器亮度，次动作（⌘/Ctrl+Enter）降低亮度。也可在动作面板选择“设置亮度…”或“设置对比度…”输入百分比，列表上方“统一亮度…”调节所有支持硬件亮度的显示器。

macOS 读取系统真实显示器状态：Apple 屏幕使用系统亮度接口，支持 DDC/CI 的外接屏使用硬件控制。亮度与对比度分别检测，不支持的控制不会出现；显示器、转接线、镜像模式及系统版本都会影响可用性。不使用软件遮罩模拟硬件亮度。

Windows：外接屏走 DDC/CI，笔记本内屏走系统背光接口，界面与 macOS 相同。

调节前核对连接和当前数值，调节后读回实际硬件档位。多屏调节失败会尝试恢复原值；若设备断开或状态已被其他操作改变，会明确提示重新扫描，不覆盖其他操作。设备采用固定档位时，最终值可能与输入百分比略有差异，以重新扫描的结果为准。

搜索“熄屏”向系统发送关闭显示器请求。是否同时锁屏由系统设置决定。

## 平台与要求

- 支持：Windows、macOS
- 需要客户端 1.1.8.5 或更新。
