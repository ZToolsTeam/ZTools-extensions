# 启动管理

查看启动应用、后台服务和计划任务。Windows 使用注册表、启动目录、服务和任务计划；macOS 读取用户及系统的 LaunchAgents、系统 LaunchDaemons。

macOS：“允许自启”与“当前运行”分别显示。按 Enter 切换下一次加载时是否允许启动，不结束当前进程，也不立即启动任务。修改前保留原配置及状态，切换后读取系统状态确认结果。

macOS 上，搜索框右侧可筛选用户配置、系统服务、计划任务、已禁用或程序丢失的配置；“恢复记录”用于撤销之前的自启状态修改。恢复前会核对配置是否仍与备份一致，后续有变化就停止。恢复的是原本有效的允许状态；macOS 可能保留一条明确的 enabled/disabled 覆盖记录。

macOS 上本插件只列出这三个目录里的 launchd 配置：“打开时登录”的 App、App 通过系统接口（SMAppService）注册在自身包内的后台项都不在列表中，请通过“系统登录项设置”（系统设置 > 通用 > 登录项与扩展）查看和管理。“计划任务”筛选指配置了 StartInterval / StartCalendarInterval 的定时 launchd 任务，“系统服务”指 /Library 下的全局 LaunchAgents 与 LaunchDaemons。修改失败时会提示失败原因并重新读取列表。macOS 读取失败会显示具体错误，不会把无权限当作没有启动项。

Windows：读取失败显示“读取启动项失败，列表不可信”，部分来源失败会标明列表不完整。

系统级配置修改需要 macOS 管理员授权，取消授权不会被显示为成功。macOS 上程序确实已丢失时，可从动作面板选择“移除失效配置（可恢复）”：原配置保留在同目录下的私有恢复目录，客户端同时保留恢复记录。恢复时原位置已有新文件、配置字节或自启覆盖状态发生变化，都会停止以保留后续改动。清理和恢复均不结束或立即启动任务，重新登录后生效。

## 平台与要求

- 支持：Windows、macOS
- 需要客户端 1.1.8.5 或更新。
- Windows 实现尚待真机复核。
