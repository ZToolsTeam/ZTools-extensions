# 公式识别

把屏幕、剪贴板和图片里的数学公式识别成 LaTeX，在本机完成，图片不会上传。印刷体（课本、论文、课件截图）和手写公式都能识别。在搜索框输入 `latex` 也能直接打开。

## 第一次使用

识别模型不随客户端安装，第一次打开「公式识别」时按 `Enter` 下载（约 114 MB，只需下载一次）。下载在客户端里进行，关掉插件也不会中断，再打开能看到进度；下载失败可以重试，已下载完整的文件会保留。下载完成后完全离线识别。

## 使用

- **截图识别公式**：ZTools 窗口先收起，拖选屏幕上的公式后按 `Enter`（`Esc` 取消）。识别出的 LaTeX 按选定的格式复制到剪贴板，并弹出系统通知。
- **识别剪贴板公式**：识别剪贴板里的图片，LaTeX 复制回剪贴板。
- **公式识别**：结果工作台。
  - 顶部「截图识别」（`⌘/Ctrl+N`）、「添加图片」（`⌘/Ctrl+O`，可多选，逐张识别）；动作面板里有「选择文件夹…」（`⌘/Ctrl+Shift+O`，递归收集最多 5 层、单次最多 100 张图片）与「识别剪贴板图片」（`⌘/Ctrl+Shift+V`），也支持直接拖入或粘贴图片与文件夹自动展开。截图和剪贴板识别成功后自动复制。
  - 右侧显示原图预览、排版后的公式和 LaTeX 源码，方便核对。预览保持原始宽高比和颜色；较早的结果可能只保留源码。
  - 成功的按 `Enter` 按当前格式复制，`⌘/Ctrl+Enter` 或 `⌘/Ctrl+E` 编辑公式；编辑页支持实时预览，`⌘/Ctrl+Enter` 保存，`Esc` 放弃修改。`⌘/Ctrl+K` 里有全部复制格式；失败的按 `Enter` 重新识别。
- **复制格式**：在工作台搜索框右侧选择：行内公式 `$…$`（默认，适合 Markdown、Typora、Obsidian、Notion）、独立公式 `$$…$$`、纯 LaTeX。选择会保存，截图识别公式和识别剪贴板公式也按它复制。
- **框选技巧**：一次框一个公式，框松一点没关系，四周的空白会自动裁掉；深色背景的截图也能识别。

## 识别范围与限制

- 每次识别一个公式（可以是多行，如方程组、矩阵、分段函数）。整页文字和公式混排时，请单独框选公式。
- 公式里夹着的中文（如「当 x>0 时」）识别不准，建议只框数学部分。
- 识别结果是 LaTeX 源码，可能有个别符号出错，重要场合请对照右侧排版结果核对。
- 不自动删除粗体、向量标记、分组或文本空格。排版成功及模型高分均不代表识别正确，请对照原图核对；「请核对」标签仅为模型分数偏低时的额外提醒。

## 平台与要求

- 支持：macOS，需要客户端 1.1.8.11 或更高版本。Windows 版待真机验证后开放。
- macOS：截图识别需要在「系统设置 > 隐私与安全性」中允许 ZTools 录制屏幕。

## 网络与数据

- 只有第一次下载模型时联网（依次尝试 ZTools 官方 CDN、Hugging Face 及其镜像；上游与镜像均锁定同一提交，文件逐个校验同一份 SHA-256）。识别不联网，图片只在本机处理。
- 框选和剪贴板图片的临时截图识别后立即删除。
- 识别结果和原图预览只保存在内存里，退出客户端后清空。最多保留 50 条已结束结果，原图预览总量不超过 4 MiB；删除结果或清空列表会同步移除预览。无界面命令不保留原图预览。
- 识别模型：[Pix2Text-MFR 1.5](https://huggingface.co/breezedeus/pix2text-mfr-1.5)（MIT 许可证）。
