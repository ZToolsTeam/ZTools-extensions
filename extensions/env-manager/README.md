# 环境变量

查看当前进程的环境变量快照，管理 Windows 用户 / 系统环境变量或 macOS 终端变量，预览清理 PATH 中已失效的目录，并在修改前保留可恢复的备份。

## 使用

- 命令：查看当前进程、管理 Windows 用户与系统变量或 macOS 终端变量（关键词如 `环境变量`、`path`、`env`）；另有"预览并清理持久配置中确认不存在的 PATH 目录""查看和恢复修改前的配置备份，复制当前变量快照"两个命令。
- 搜索框右侧切换视图：全部变量、用户配置（macOS 为终端配置）、系统配置（仅 Windows）、当前进程（只读）、PATH 目录明细、含失效目录的 PATH、修改备份。
- 配置中的变量：`Enter` 编辑，`⌘/Ctrl+Enter` 复制值，`⌘/Ctrl+K` 中可移除变量或预览清理 PATH。当前进程的变量：`Enter` 复制值，`⌘/Ctrl+Enter` 写入持久配置。修改备份：`Enter` 预览恢复原配置。
- 新建、编辑、移除、清理和恢复都会先显示修改摘要和位置（清理时列出要移除的目录），确认后先保存并校验原配置备份，再写入并读回核验，完成后才提示成功。
- macOS：支持 zsh 和 Bash。zsh 写入 `$ZDOTDIR/.zshrc`（未设置时为 `~/.zshrc`），Bash 写入 `~/.bash_profile`，只改动文件中的 ZTools 管理段，其余内容保持原样。变量值按字面量保存，`$HOME`、反引号和命令表达式不会执行；新开的终端加载该文件后生效，其他启动脚本仍可能影响最终值。Bash 没有 `.bash_profile` 但已有 `.bash_login` 或 `.profile` 时会停止，不新建会遮蔽它们的文件。写入时原文件另存在同目录的 `.ztools-env-recovery-*` 文件夹中，成功提示会给出路径。
- Windows：读取当前用户与系统注册表中的环境变量原值；修改系统变量需要相应权限；重新登录后启动的应用才会继承新环境。
- 当前进程快照只读，修改配置不会改变已经运行的应用。
- PATH 清理只移除确认不存在的本地绝对目录；空项、相对路径、无法确认的路径、外部卷和含变量引用的目录保留，顺序不变；清理后 PATH 会变空时停止。
- 恢复备份时，如果配置在该备份之后又被修改过，会停止以免覆盖，备份仍保留。
- "复制变量快照"复制当前读取到的真实值，可能包含密钥，请妥善保管。

## 平台与要求

- 支持：Windows、macOS
- 需要客户端 1.1.8.5 或更新。
- Windows 实现尚待真机复核。

## 网络与数据

- 不联网，修改备份只保存在本机。
