# 表格互转

离线转换剪贴板中的表格文本，不读取文件或连接数据库。Excel 请先复制单元格；不直接导入 `.xlsx` 文件。

打开后读取剪贴板，选择输出格式，按 Enter 复制完整结果，⌘/Ctrl+Enter 直接粘贴到当前应用。预览最多显示 100 行、3 万字符，不影响复制内容。顶部「编辑输入」可以修改原文、指定输入格式和 SQLite 表名；自动识别有歧义时可手动选择。表头下拉用于 CSV、TSV、Markdown、HTML 和 JSON 二维数组；JSON 对象数组和 SQL 使用自身列名。

- 支持 CSV、TSV、JSON 对象数组或二维数组、Markdown 表格、HTML 文字表格，以及一条 SQLite `INSERT INTO ... (列名) VALUES (...)` 语句。
- CSV/TSV 保留引号内换行、空格、空字符串和末尾空列；引号错误或列数不一致时停止转换。空表头和重复表头会自动命名并提示，避免覆盖列。
- JSON 输出保留对象数组中的嵌套对象、数组、字符串、布尔值、null 和缺失键。文本列仅把能安全往返的数字和小写 true/false 转为数值或布尔值；长整数、前导零、负零、带空格的数字保留为字符串。JSON 中超出精度的裸数字、负零和重复键会报错，应先把精确数字加引号。
- CSV、TSV、Markdown 和 HTML 是文字表格，不携带 JSON 类型。输出时嵌套值转为 JSON 文本，null 与缺失键显示为空单元格；要保留完整类型请用 JSON。CSV 内容在电子表格软件中仍会按该软件的规则解释。
- Markdown 输入兼容 GFM 短分隔行（如 `|-|-|`、`|:-:|`）。Markdown 输出把 `| * _ ` [ ]` 等格式符号写成数字实体；只有像网址或邮箱的单元格才额外转义 `. : @ ( )`，避免被自动识别为链接，普通小数和时间保持原样。
- HTML 仅接收一个完整文字表格，支持常见行内标签、br、数字实体及 amp/lt/gt/quot/apos/nbsp；合并单元格、嵌套/多个表格、图片等不支持的内容会明确报错，不会忽略后继续输出。
- SQL 输入输出明确使用 SQLite 字面量语法，反斜杠按原字符保留。仅支持字符串、数字、布尔值、NULL 的 VALUES，不支持函数、表达式、注释、后续语句或 MySQL 反斜杠转义。标识符使用双引号并转义；大小写重名列会拒绝 SQL 输出。嵌套值转为 JSON 字符串，缺失键映射 NULL。插件始终只处理 SQL 文本，从不执行 SQL。

读取失败保留上次输入并提示；解析失败保留原文，可编辑重试。空剪贴板清除旧结果，不填充示例数据。某个输出格式失败时，其他格式仍可用。

单次输入最多 200 万字符、1000 列、5 万行、20 万个单元格；单个输出不超过剪贴板 8 MiB 上限。输出逐行检查预算，超限后提示拆分。Markdown 对齐填充最多 80 字符，不截断单元格内容。

## 平台与要求

- 支持：Windows、macOS

## 网络与数据

- 不联网，数据只保存在本机。

## 开发检查

在插件仓库根目录执行：

```sh
node scripts/build-declarative.mjs table-converter
node --test extensions/table-converter/tests/*.test.mjs
```

界面使用列表加真实输出预览，编辑采用声明式表单。复制、粘贴和错误反馈测试用声明式 SDK 运行时加模拟宿主，不读写系统剪贴板。
