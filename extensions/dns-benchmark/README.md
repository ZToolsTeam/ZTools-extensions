# DNS测速

macOS 使用真实 DNS A 记录查询，逐个测量公共地址解析 `example.com` 的耗时。这里是一次查询的结果，不代表所有网站或长期网络表现；失败不会被换成固定延迟。

macOS：

- 在右上角选择已连接的网络服务，等待测速完成，选中地址按 Enter 应用。一次应用所选的一个地址；⌘+Enter 复制地址。
- 修改 DNS 会请求 macOS 管理员授权。写入前会保存原配置；原配置已被其他程序修改时停止，请重新测速并读取配置后再操作。
- 列表下方的「恢复自动 DNS」清除手动地址；「恢复最近备份」恢复该网络上一次操作前保存的地址。备份按网络服务保留，失败操作的备份也保留。
- 「刷新 DNS 缓存」单独请求管理员授权。取消授权或命令失败都会显示失败，不会显示已刷新。
- 测速和系统授权等待期间可点击「取消」。如果系统已经进入提交阶段，会先完成应用或恢复再返回实际结果；取消请求不表示已经撤销成功的修改。
- 如果提示「写入状态未确认」，先重新读取系统配置，再决定是否恢复备份，避免覆盖其他软件的网络设置。

Windows：按各 DNS 的 TCP 53 端口连接延迟排序（不是解析耗时），用 netsh 切换，需要以管理员身份运行。

## 平台与要求

- 支持：Windows、macOS
- 需要客户端 1.1.8.5 或更新。
- macOS 需要客户端带有 DNS 配置组件。没有安装 Xcode 命令行工具的源码运行环境可能缺少该组件；正式 Mac 安装包构建会包含它。
- Windows 实现尚待真机复核。

## 网络与数据

- 测速只连接插件内置的 15 组公共 DNS 地址（阿里云、腾讯 DNSPod、114、Cloudflare、Google 等）：macOS 向每个地址查询 `example.com` 的 A 记录，Windows 连接每个地址的 TCP 53 端口。
