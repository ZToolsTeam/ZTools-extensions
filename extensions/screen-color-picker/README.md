# 屏幕取色

读取屏幕上鼠标指针所在位置的像素颜色，并在 HEX、RGB、HSL、HSV、CMYK 等格式之间换算和复制。

## 使用

- 命令：`屏幕取色`
- 在搜索框输入 HEX（如 `#0A84FF`）、`rgb(...)`、`hsl(...)` 或颜色名称，列表显示各格式的换算结果与 WCAG 对比度。
- 取色：点顶部"屏幕吸色"按钮，或在动作面板里选"屏幕吸色"。读取的是触发那一刻鼠标指针所在位置的一个像素，没有放大镜界面；取到后按"默认复制色彩格式"写入剪贴板。取色时插件窗口不会隐藏，用鼠标点按钮取到的是按钮处的颜色；要取别处的颜色，先把指针移到目标位置（不能被 ZTools 窗口遮住），再在 HEX 一行按 Ctrl+K 打开动作面板选择"屏幕吸色"。
- 选中某种格式按 Enter 复制（HEX 一行按 Enter 打开颜色详情，Ctrl+Enter 复制）；详情页可复制各格式、查看配色方案，或把颜色直接粘贴到前台应用。
- 可把当前颜色收藏到调色板（最多 30 个），也可移除或清空。
- 取色失败时提示失败原因。

## 平台与要求

- 支持：仅 Windows
