# 图片识字

用 Windows 系统自带的文字识别（Windows.Media.Ocr）在本机识别图片和屏幕截图里的文字。

## 使用

- 命令：图片识字。
- 打开后扫描“图片”“桌面”“下载”文件夹中的 png、jpg、jpeg、webp、bmp 图片，默认全部勾选。
- `Enter` 识别全部已勾选的图片，`Ctrl+Enter` 截取主屏幕整屏并识别、把文字复制到剪贴板，`Ctrl+K` 打开动作面板（复制这张图片的识别结果、在资源管理器中显示）。截屏时 ZTools 窗口不会隐藏，窗口里的文字也会被识别。
- 搜索框旁的下拉框选择识别语言：简体中文（默认）、英文、日文、韩文，批量识别和截屏识别都按所选语言识别。需要 Windows 已安装该语言的 OCR 语言包，没装时 Windows 会改用系统语言识别。
- 右侧可选排版方式（保持识别出的分行、合并为单行、按文件汇总为 Markdown 表格：每张图片一行，含文件名和识别内容）和识别后的动作（复制到剪贴板、导出同名 .txt 或 .md 文件、两者都做）。识别失败的图片会标出原因，不计入结果。
- 导出时先选择保存结果的文件夹，每张图片写一个同名文件；同一批里重名的自动加序号，文件夹里已有同名文件时不覆盖，会提示哪些没有导出。
- “删除页码行和印章文字行”只从识别结果里删掉页码行和含“合同专用章”“骑缝章”等字样的行，不处理图片本身。
- Windows 识别失败时，如果电脑上装有 tesseract 命令行程序会改用它（选英文时按英文识别，其余语言都按简体中文加英文识别），两者都失败时提示两边的原因。

## 平台与要求

- 支持：仅 Windows
