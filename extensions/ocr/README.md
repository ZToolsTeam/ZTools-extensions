# 文字识别

用系统自带的文字识别（macOS 的 Vision、Windows 的系统文字识别），在本机识别屏幕、剪贴板和图片里的文字。在搜索框输入 `ocr` 也能直接打开。

## 使用

- **截图识别文字**：ZTools 窗口先收起，拖选屏幕上的区域后按 `Enter`（`Esc` 取消）。识别出的文字直接复制到剪贴板，并弹出系统通知。
- **识别剪贴板图片**：识别剪贴板里的图片，结果复制回剪贴板。剪贴板里没有图片时会提示。
- **文字识别**：结果工作台。
  - 顶部「截图识别」：框选识别，完成后窗口重新出现，结果自动复制。
  - 顶部「添加图片」（`⌘/Ctrl+O`）：一次可选多张，选好后逐张识别。
  - 动作面板里的「识别剪贴板图片」（`⌘/Ctrl+Shift+V`）。
  - 每条结果的右侧显示完整文字。`Enter` 复制文字，`⌘/Ctrl+R` 重新识别失败的图片，`⌘/Ctrl+Shift+C` 复制全部结果，`⌘/Ctrl+K` 里可以在文件管理器中显示原图或从列表移除。
  - 搜索框按文件名和识别出的文字过滤。
- **识别语言**：在工作台搜索框右侧选择，可选简体中文（默认，中英混排）、英文、日文、韩文。选择会保存，截图识别文字和识别剪贴板图片也按它识别。
- **支持的图片**：PNG、JPEG、BMP、GIF、TIFF；macOS 另支持 HEIC、WebP（Windows 需要系统装有对应的图片扩展）。macOS 单张不超过 16 MB，超出识别上限的大图会先缩小再识别。

## 平台与要求

- 支持：macOS、Windows，需要客户端 1.1.8.9 或更高版本。
- macOS：截图识别文字需要在「系统设置 > 隐私与安全性」中允许 ZTools 录制屏幕。
- Windows：所选识别语言需要已安装对应的 Windows OCR 语言包（「设置 > 时间和语言 > 语言」里添加该语言并安装「光学字符识别」），没装时会提示。
- Windows：截图识别和剪贴板识别已于 2026-11-03 完成真机验证。

## 网络与数据

- 不联网，图片只在本机识别。
- 框选和剪贴板图片的临时截图识别后立即删除。
- 识别结果只保存在内存里，退出客户端后清空。
