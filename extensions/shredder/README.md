# 文件粉碎

选择文件或文件夹导入待粉碎列表，勾选后先多次覆写文件内容，再改名删除。

## 使用

- 命令：`文件粉碎`
- 打开时不自动扫描任何本机目录；通过顶栏「选择文件」「选择文件夹」、拖入或粘贴导入待粉碎文件（选择文件夹时递归收集非空普通文件，自动跳过 Windows 系统目录及内部文件）。
- 顶部下拉框选择覆写方式：3 次（全 0、全 1、随机，参照 DoD 5220.22-M）、7 次（全 0、全 1、5 次随机）、1 次（全 0）。覆写后改成随机文件名再删除。
- 新导入的文件默认不勾选；粉碎前会弹出确认框，逐个列出将被粉碎的文件（超过 10 个时注明其余数量），取消则不做任何处理。
- 只处理已勾选的文件。粉碎成功的文件从列表中移除；有文件失败时提示成功和失败的数量及失败原因，失败的文件保留在列表中。
- 动作面板支持「从列表移除」（`Ctrl+Backspace`）与「清空列表」（`Ctrl+Shift+Backspace`），仅清理界面列表，不删除磁盘文件。
- 在 SSD、存在系统还原点或卷影副本等快照、以及写时复制的文件系统上，覆写不一定落在原来的存储位置，不能保证数据无法恢复。

## 平台与要求

- 支持：仅 Windows

## 网络与数据

- 不联网，不保存数据。
