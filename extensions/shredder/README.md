# 文件粉碎

列出临时文件夹与崩溃转储目录里的文件，勾选后先多次覆写文件内容，再改名删除。

## 使用

- 命令：`文件粉碎`
- 候选文件只来自 `%TEMP%` 与 `%LOCALAPPDATA%\CrashDumps`（包括子目录里的文件，合计最多列出 30 个）；左侧按"临时文件夹""崩溃转储"分类。不能添加其他位置的文件或文件夹。
- 顶部下拉框选择覆写方式：3 次（全 0、全 1、随机，参照 DoD 5220.22-M）、7 次（全 0、全 1、5 次随机）、1 次（全 0）。覆写后改成随机文件名再删除。
- 打开时不勾选任何文件。右侧文件行和左侧"全部候选文件"按 Enter 粉碎已勾选的文件；左侧其他分类行按 Enter 只切换右侧列表，按 Ctrl+Enter 才粉碎。右侧文件行按 Ctrl+Enter 在资源管理器中定位。
- 粉碎前会弹出确认框，逐个列出将被粉碎的文件（超过 10 个时注明其余数量），取消则不做任何处理。
- 只处理已勾选的文件。粉碎成功的文件从列表中移除；有文件失败时提示成功和失败的数量及失败原因，失败的文件保留在列表中。
- 在 SSD、存在系统还原点或卷影副本等快照、以及写时复制的文件系统上，覆写不一定落在原来的存储位置，不能保证数据无法恢复。

## 平台与要求

- 支持：仅 Windows

## 网络与数据

- 不联网，不保存数据。
