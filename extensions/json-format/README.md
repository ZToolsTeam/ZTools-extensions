# JSON 格式化

JSON 语法校验、美化与压缩，并可根据 JSON 生成 TypeScript / Rust / Go 类型定义。

## 使用

- 命令：JSON 美化与语法校验、JSON 生成 TypeScript / Go / Rust 类型；关键词如 `json格式化`、`json转ts`。
- 实时校验语法，错误定位到行列（多行输入、单引号、末尾逗号等都能定位）；支持 2 格 / 4 格 / Tab 缩进（动作面板里直接复制只提供 2 格和 4 格两种）。
- 可在动作面板中从剪贴板读取（已有输入时只用合法 JSON 覆盖）；JSON 合法时才提供复制美化版、压缩单行版与类型定义。
- 类型推导：键名含连字符、中文时生成合法标识符并保留原始键（serde rename / json tag）；不同对象下的同名键结构不同时生成不同类型。
- 长整数不丢精度：格式化、压缩、JSONPath 与类型推导都按原文数字处理，超出 i64 的整数推导为 u64，小数（含 1.0）推导为浮点。
- 输入框内 `⌘/Ctrl+Enter` 格式化并进入详情页（格式化结果、类型定义与 JSONPath 路径列表），`⌘/Ctrl+K` 打开动作面板，`Esc` 返回。
- 「JSON 生成类型」命令：主动作是「生成类型代码」，直接进入只含 TypeScript / Go / Rust 类型代码的结果页，不显示缩进选项。

## 平台与要求

- 支持：Windows、macOS
- 客户端已内置，无需单独安装。

## 网络与数据

- 不联网，数据只保存在本机。
