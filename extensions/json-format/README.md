# JSON 格式化与类型推导 (json-format)

基于 ZTools 最新纯声明式 UI 架构与原生声明式组件库开发的 JSON 工具插件。

## 功能亮点
- **零 CSS 样式与零 HTML**：完全基于 `@ztools/declarative-ui` 声明式组件构建，由宿主统一渲染 Fluent / Mica 亚克力亚态毛玻璃；
- **智能校验与即时格式化**：实时校验 JSON 语法，错误精确到行列（多行输入、单引号、末尾逗号等都能定位）；支持 2 格 / 4 格 / Tab 缩进；
- **一键压缩与剪贴板联动**：从剪贴板读取（已有输入时只用合法 JSON 覆盖）；JSON 合法时才提供复制美化版、压缩单行版与类型定义；
- **TypeScript / Rust / Go 类型推导**：键名含连字符、中文时生成合法标识符并保留原始键（serde rename / json tag）；不同对象下的同名键结构不同时生成不同类型；
- **长整数不丢精度**：格式化、压缩、JSONPath 与类型推导都按原文数字处理，超出 i64 的整数推导为 u64，小数（含 1.0）推导为浮点；
- **全键盘闭环**：输入框内 `⌘Enter`（Windows 为 `Ctrl+Enter`）格式化并进入详情页，`⌘K` / `Ctrl+K` 唤起动作面板，`Esc` 返回。
