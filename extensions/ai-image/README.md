# AI 图片修复

开发中，暂不在插件市场提供：AI 超分辨率、去背景、人像修复需要客户端提供本地 AI 推理能力（模型与推理组件），当前客户端的图片处理接口只能做普通插值放大；等客户端提供该能力并在 Windows 上实测通过后再发布。

把 PNG、JPG、BMP 图片按 2 倍或 4 倍放大像素尺寸。目前只有「普通放大（非 AI）」可用：这是插值放大，不补充细节，也不提升清晰度。

## 使用

- 命令：AI 图片修复（插件主命令）。
- 打开后扫描图片、桌面、下载目录里的 PNG、JPG、BMP 图片（每个目录最多列出 40 张），按大小降序排列；不支持 WebP。
- 搜索栏右侧选择处理方式。AI 超分辨率、AI 去背景、AI 人像修复标为「暂不可用」，选中后不会处理任何文件。左侧设置放大倍率（2 倍 / 4 倍）和输出格式（PNG / JPG）。
- `Enter` 处理已勾选的图片（多于 1 张时先确认）；`Ctrl+Enter` 在资源管理器中显示（处理成功后显示输出文件）；`Ctrl+K` 打开动作面板，可只处理当前图片。
- 输出到原图所在目录，文件名为 `原名_2x_<日期-时间>.png` 这类格式，重名时再加序号；不覆盖已有文件，也不修改原图。
- 单张失败不影响其他图片，失败的行标「处理失败」并显示原因；客户端没有返回输出文件的路径和大小时按失败处理。
