# 网页书签

只读聚合本机浏览器各个配置里的网页书签，可按中文、拼音、网址或文件夹检索，打开或复制书签。

## 使用

- 命令：聚合检索全部浏览器的收藏网页书签（关键词如 `书签`、`bookmarks`）；另有只看 Edge、Chrome、Firefox，以及只看 360 安全浏览器、360 极速浏览器与 QQ 浏览器的命令。
- 输入标题、拼音全拼或首字母、网址或文件夹名检索；输入 `domain:example.com` 按域名筛选。搜索框右侧可按浏览器筛选。
- `Enter` 打开网页，`⌘/Ctrl+Enter` 复制链接，`⌘/Ctrl+K` 中还可复制 Markdown 链接或标题。
- 每次显示 200 条，末尾的"显示更多"继续加载；搜索始终覆盖全部已读取的书签。
- "刷新书签"重新读取。部分来源读取失败时可打开"读取详情"查看原因；全部读取失败时保留上次结果并提示未更新。
- 支持的浏览器：Windows 上的 Chrome、Edge、Brave、Firefox、QQ 浏览器、360 极速浏览器、360 安全浏览器；macOS 上的 Chrome、Edge、Brave、Firefox、Safari、QQ 浏览器、360 极速浏览器。读取默认数据目录下的各个配置，Firefox 还读取 `profiles.ini` 中登记的自定义配置；只在云端、尚未同步到本机的书签读不到。
- 只列出 HTTP / HTTPS 网页，不执行书签脚本。Firefox 数据库以只读方式读取，包括尚未合并的 WAL 日志。Safari 书签受系统隐私权限保护，权限不足时会显示具体提示。
- 单个书签文件最多 16 MiB，单个 Firefox 数据库最多 1 GiB，总结果最多 20000 条或 7 MiB；超出的来源会明确报错，不会当作完整载入。

## 平台与要求

- 支持：Windows、macOS
- 需要客户端 1.1.8.5 或更新。

## 网络与数据

- 不联网，只读取本机的书签文件，不修改浏览器收藏夹。
