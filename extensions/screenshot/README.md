# 截图历史

浏览本机截图目录，回贴、复制、定位、置顶与批量清理截图；也可以立即截取全部屏幕。

## 使用

- 命令：截图历史。
- 截图来源：macOS 扫描系统设置的截图保存位置、桌面上按截图命名的文件、`图片/Screenshots` 以及 Spotlight 标记为截图的文件；Windows 扫描 `图片\Screenshots`、OneDrive 的 `图片\Screenshots` 和 `图片` 目录下的图片。置顶的排在最前，其余按修改时间从新到旧排序。
- 立即截取：截取全部显示器（截取前自动隐藏 ZTools 窗口），PNG 文件保存在 ZTools 缓存目录，只在本次运行期间显示在列表中；可在工作台选择截取后是否复制到剪贴板。
- `Enter` 回贴到活动窗口，`⌘/Ctrl+Enter` 复制图片，`⌘/Ctrl+K` 打开动作面板（复制路径、定位、打开、置顶、删除等）。自动粘贴不可用时改为复制图片并提示手动粘贴；macOS 上自动粘贴需要在系统设置的辅助功能中授权 ZTools。
- 复制、回贴、打开或定位时如提示路径未授权，在动作面板中选择「授权访问截图目录」，选中截图所在目录后重试。
- 单张删除不经确认：扫描到的截图移入废纸篓 / 回收站，本次立即截取的文件直接删除。批量清理只作用于当前列表中已勾选且未置顶的截图，执行前需确认。
- 不提供框选区域、标注与悬浮贴图。

## 平台与要求

- 支持：Windows、macOS
- 文字识别（OCR）只在 Windows 上提供，其他平台不显示识别入口。

## 网络与数据

- 不联网，数据只保存在本机。
