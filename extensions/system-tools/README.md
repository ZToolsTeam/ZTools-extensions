# 系统工具

把锁屏、睡眠、休眠、重启、关机、注销、系统音量与静音、显示隐藏文件、清空回收站、防止熄屏等系统操作集中在一个列表里，选中后回车执行。

## 使用

- 命令：在启动框输入 `系统工具`、`锁屏`、`关机`、`静音`、`清空回收站` 等关键词打开。列表里只有下面这些系统操作，不提供注册表、组策略、服务管理、设备管理器等入口。
- 搜索框右侧按类别筛选：电源与会话、系统声音、文件与维护。
- `Enter` 执行选中的操作。
- 重启、关机、注销、清空回收站标有"执行前确认"，回车后先弹出确认，取消则不执行；没有跳过确认的方式。
- 调高、调低音量和静音相当于按一次键盘上的对应按键。
- 休眠需要系统已启用休眠功能。
- 切换显示隐藏的文件后，已打开的资源管理器窗口需要刷新才会生效。
- 防止熄屏开启后屏幕保持常亮、电脑不自动睡眠，再执行一次关闭，退出 ZTools 后失效。
- 执行失败时提示客户端返回的原因，不会报成功。

## 平台与要求

- 支持：仅 Windows

## 网络与数据

- 不联网，数据只保存在本机。
