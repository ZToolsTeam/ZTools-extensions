# 常用文件夹

列出当前用户的常用文件夹，选中后直接打开。

## 使用

- 命令：`常用文件夹`
- 按系统列出常用目录：桌面、下载、文档、图片、视频（macOS 为影片）、音乐、用户主目录；Windows 另有 AppData Roaming、AppData Local、系统盘和临时文件夹，macOS 另有应用程序、Application Support、资源库、缓存和临时文件夹。只显示本机存在的目录。
- 选中目录按 Enter 在文件管理器中打开，⌘/Ctrl+Enter（或 ⌘/Ctrl+C）复制完整路径。
- 搜索框可按名称、路径或说明筛选。

## 平台与要求

- 支持：Windows、macOS

## 网络与数据

- 不联网，不保存数据。
