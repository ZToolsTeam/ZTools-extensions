# 取色与配色

颜色值格式互转与 WCAG 对比度检查，可把常用颜色收藏到调色板。

## 使用

- 命令：色值转换（关键词如 `hex转rgb`、`颜色转换`）、无障碍对比度检测（`对比度`、`wcag`）。对比度检测输入前景色和背景色（如 `#333333 #FFFFFF`），给出两者的对比度与正文 / 大字的 AA、AAA 是否通过；只输入一种颜色时分别计算白底和黑底。
- 输入 `#RGB`、`#RRGGBB`、`#RRGGBBAA`、`rgb()`、`hsl()`、`hsv()`、`oklch()`、`cmyk()` 或颜色英文名，列出 HEX、RGB、HSL、OKLCH、HSV、CMYK、带透明度的 HEX、Tailwind 任意值与 CSS 变量写法；超出 sRGB 色域时按最接近的颜色换算并注明。
- 右侧显示色块、白字 / 黑字对比度与 WCAG 等级（AAA / AA / AA Large / Fail）、推荐文字颜色，以及互补色、类似色、三色配色和单色渐变。
- 在各种写法上按 `Enter` 复制，`⌘/Ctrl+Enter` 收藏到调色板，`⌘/Ctrl+K` 打开动作面板（粘贴到当前应用等）。调色板中的颜色按 `Enter` 复制 HEX，`⌘/Ctrl+Enter` 查看各种写法，移除与清空在动作面板中。调色板最多 100 个颜色，移除单个颜色和清空前都会确认。
- 不提供屏幕取色（吸管）。

## 平台与要求

- 支持：Windows、macOS
- 客户端已内置，无需单独安装。

## 网络与数据

- 不联网，数据只保存在本机。
