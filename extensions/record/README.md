# 屏幕录制

把整个桌面（所有显示器）录制为 MP4 视频或 GIF 动图，可选帧率。不录制声音，需要本机已安装 ffmpeg。

## 使用

- 命令：屏幕录制（插件主命令）。
- 左侧选择帧率（15 / 30 / 60 FPS）和输出格式（MP4 / GIF），点顶部「开始录制」或按 `Ctrl+Shift+R` 开始；再次点击或按 `Ctrl+Shift+R` 停止并保存。
- 只能录整个桌面，不能只录某个区域或窗口；系统声音和麦克风都不录。
- 已有录制在进行时不会再开始第二个；本机没有 ffmpeg，或命令行中不能直接运行 ffmpeg 时，开始录制会提示失败。
- 离开插件界面后录制不会停止；重新打开本插件会显示「正在录制」，可在这里停止并保存。退出 ZTools 时会结束录制并保存文件。
- 录制文件保存在系统「视频」文件夹下的 `ZTools_Recordings` 目录，右侧按时间倒序列出其中的 MP4 / GIF：`Enter` 打开，`Ctrl+Enter` 在文件夹中显示，`Ctrl+K` 打开动作面板（可复制文件路径）。

## 平台与要求

- 支持：仅 Windows
- Windows 实现尚待真机复核。

## 网络与数据

- 不联网，数据只保存在本机。
