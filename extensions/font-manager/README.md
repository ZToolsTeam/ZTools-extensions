# 字体管理

检索本机已安装的字体，用你输入的文字查看实际字形，并查看字体文件附带的许可与版权信息。

## 使用

- 命令：字体管理（关键词如 `字体预览`、`fonts`）、字体许可（`字体授权说明`）、未附许可字体（`字体版权信息`）；后两个打开后分别预先筛选“含许可说明”“未附许可说明”的字体。
- 搜索框按字体名称或样式过滤，旁边的下拉框可切换全部字体、含许可说明、未附许可说明、系统字体。
- 右侧显示用所选字体绘制的预览图；所选字体缺少部分字形时会给出提示（macOS 上会列出补绘用的系统回退字体）。顶部“设置预览文字”可修改预览内容（最多 160 个字符）。
- `Enter` 复制字体名称，`⌘/Ctrl+Enter` 复制 CSS `font-family` 写法，`⌘/Ctrl+K` 打开动作面板（定位字体文件、查看许可信息）。
- 许可信息页显示字体自带的许可说明、版权与制造商原文，不能据此直接判断是否允许免费商用。
- 不提供安装或卸载字体。

## 平台与要求

- 支持：Windows、macOS
- 需要客户端 1.1.8.5 或更新。

## 网络与数据

- 不联网，数据只保存在本机；许可信息页的“打开字体提供的许可链接”会用系统浏览器打开字体文件里写明的地址。
