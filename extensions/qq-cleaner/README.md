# QQ 清理

扫描电脑端 QQ、TIM 的本地缓存目录，按日志、图片、视频、语音、接收文件等分组列出文件，勾选后移入回收站；聊天记录数据库不能勾选。

## 使用

- 命令：`QQ 清理`
- 扫描位置：文档下的 `Tencent Files`（以及 C 到 G 盘根目录下的 `Tencent Files`）、`%APPDATA%\Tencent` 下的 Users、Logs、QQ、TIM、QQTempSys，`%APPDATA%\QQ`，`%LOCALAPPDATA%\Tencent` 下的 MiniBrowser、QQGuild、Misc。
- 左侧按 12 个清理分组和聊天库保护区汇总，顶部下拉框按 QQ 号筛选；右侧列出文件，可逐个勾选或全选。
- 扫描后只默认勾选右侧显示出来的、属于日志、账号运行缓存、系统内核缓存、内置浏览器与小程序、头像缓存、接收表情缓存这些分组的文件；没显示出来的文件不会被勾选，用途无法识别的文件（归入“账号运行缓存”显示，标为“用途未识别”）也不默认勾选。聊天图片、视频、语音（清理后聊天里可能无法再查看）、收藏表情、接收的文件、登录会话数据默认不勾选。"接收的文件"里可能有你需要的文档，勾选前请核对。
- 选中文件按 Enter 清理已勾选的文件，确认框按分组列出文件数和大小，确认后移入回收站；Ctrl+Enter 在资源管理器中定位；Ctrl+K 里可勾选或取消、用默认程序打开、复制路径。
- 清理后的提示给出实际移入回收站的文件数；有文件没能移入回收站（例如正被 QQ 占用）时，提示失败的数量和原因，不会改为永久删除。文件移入回收站后仍占用磁盘空间，清空回收站后才会释放。
- 每个扫描目录最多读取 140 个文件，左侧部分分组的体积还计入了没有读取到的文件；右侧按体积从大到小最多显示 60 个，选左侧分组或搜索可以看到其它文件，表头复选框只勾选或取消当前显示出来的文件。清理范围是当前 QQ 号筛选下所有已勾选的文件，勾选数量见顶部状态栏。
- `Msg3.0.db`、`nt_msg.db`、`Registry.db`、`Info.db` 等聊天记录与账号数据库，以及 `nt_db` 目录下的文件，不能勾选，也不会被清理。

## 平台与要求

- 支持：仅 Windows

## 网络与数据

- 不联网，不保存数据。
