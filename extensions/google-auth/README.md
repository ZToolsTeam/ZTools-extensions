# 2FA 验证码

按 RFC 6238 生成两步验证动态口令（TOTP），口令随倒计时自动刷新，可直接复制。

## 使用

- 命令：2FA 验证码（关键词如 `2fa`、`totp`、`验证码`）。
- 添加账号：在动作面板选「添加 2FA 账号」（还没有账号时直接按 `Enter`），填写名称和 Base32 密钥，或直接粘贴 `otpauth://totp/...` 链接自动填好各项；支持 6 / 8 位、30 / 60 秒、SHA1 / SHA256 / SHA512。不支持 HOTP（计数器型）链接，也不能识别二维码图片。
- 列表显示每个账号的当前口令和剩余秒数：`Enter` 复制口令，`⌘/Ctrl+K` 打开动作面板（复制 Base32 密钥、添加、删除账号等）。
- 删除前会确认，删除后密钥无法找回；没有编辑功能，修改需删除后重新添加。

## 平台与要求

- 支持：Windows、macOS
- 客户端已内置，无需单独安装。

## 网络与数据

- 不联网，数据只保存在本机。
- 账号与密钥保存在客户端提供的系统加密存储中；系统加密存储不可用时只读显示旧版明文中的账号，暂停添加与删除。旧版以明文保存的账号会在打开时迁移到加密存储，迁移成功后删除明文。
