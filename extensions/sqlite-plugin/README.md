# SQLite 查看器

在 AppData 下查找 SQLite 数据库文件，只读查看表名、行数、列和记录，并把记录导出为文本复制到剪贴板。

## 使用

- 命令：`SQLite 查看器`
- 自动在 `%APPDATA%` 与 `%LOCALAPPDATA%` 下查找 `.db`、`.sqlite`、`.sqlite3` 文件，最多列出 12 个，在顶部下拉框切换；不保证找全，也不能手动打开其他位置的文件。找不到数据库或读取失败时，状态条显示原因。
- 左侧列出所有表和视图，以及行数和列；选中一张表后，右侧显示这张表的前 50 行。打开时不勾选任何记录，没有勾选时导出当前列表中的全部记录。
- 选中记录按 Enter 导出为 JSON，Ctrl+Enter 导出为 SQL INSERT 语句，Ctrl+K 里可导出为 CSV 或在资源管理器中定位数据库文件；左侧表行按 Ctrl+Enter 导出为 JSON。导出结果复制到剪贴板，复制失败时提示原因。
- 导出内容是记录的原始字段值：JSON 为对象数组，CSV 第一行是列名，SQL INSERT 写明表名和列名；二进制字段导出为十六进制文本。只包含已读取的前 50 行，不是整表导出。
- 只读：不执行写入或 VACUUM 等整理语句，不修改数据库文件。读取的是数据库主文件，正在被其他程序使用的数据库可能看不到最新写入的内容。

## 平台与要求

- 支持：仅 Windows

## 网络与数据

- 不联网，不保存数据。
