# 网段与权限计算

计算 IPv4 CIDR 网段的子网掩码、可用地址范围与二进制掩码，以及 Linux chmod 八进制与符号权限的互相转换，全部离线完成。

## 使用

- 命令：计算 IPv4 CIDR 子网掩码范围或双向转换 Linux chmod 权限（关键词如 `cidr`、`chmod`、`子网计算`）。
- 在搜索框直接输入，按内容自动切换模式：`755`、`rwxr-xr-x`、`chmod 755` 这类按权限计算，含 `.` 或 `/` 的按 CIDR 计算；也可以在搜索框右侧切换。
- CIDR 结果行：`Enter` 复制可用 IP 范围，`⌘/Ctrl+Enter` 复制子网掩码，`⌘/Ctrl+K` 中可复制网络地址/CIDR。权限结果行：`Enter` 复制 chmod 命令，`⌘/Ctrl+Enter` 复制八进制值，`⌘/Ctrl+K` 中可复制符号值。下方的常用网段与常用权限按 `Enter` 载入计算。
- CIDR 支持 `/0` 到 `/32`，省略前缀时按 `/24`；也可以写子网掩码，如 `192.168.1.5 255.255.255.0`、`192.168.1.5/255.255.255.0` 或 macOS `ifconfig` 里的十六进制掩码 `192.168.1.5/0xffffff00`，掩码必须连续；IPv4 必须是四段不带前导零的十进制数字。`/31` 按点对点链路计 2 个地址，`/32` 表示单个主机，二者没有独立广播地址。可用主机数是数学结果，不排除其中的特殊用途地址。
- 显示输入地址的用途分类（私有地址、回环、链路本地、文档示例、组播、保留等，依据 IANA IPv4 特殊用途地址登记）；分类只针对输入的 IP，不探测可达性。
- 权限支持 3～4 位八进制（如 755、4755、1777）、9 位符号（如 rwxr-xr-x、rwsr-xr-x、rwxrwxrwt）和带文件类型前缀的 ls 写法（如 drwxr-xr-x，末尾带 macOS 的 `@` / `+` 或 Linux 的 `.` 标记也可以），区分 s/S/t/T。也可以输入 `chmod 755` 或 `chmod -R 755`，但后面不能再带文件名，否则提示格式错误；复制的命令模板里的 `<file>` 需要自行替换，插件不执行任何命令。
- 其他用户有写权限时会提示。不考虑 ACL、文件标志、用户身份等实际访问控制条件。

## 平台与要求

- 支持：Windows、macOS

## 网络与数据

- 不联网，计算全部在本机完成。
