# 快捷短语

保存常用文字模板（开票信息、地址、话术、代码片段等），使用时直接粘贴到原输入位置或复制，内容里可以用日期、时间、剪贴板变量。

## 使用

- 命令：`快捷短语`（也可输入 `常用语`、`snippets`）；按分类打开：`开票信息`、`常用地址`；新建：`新建短语`
- 列表初始为空，用顶部"新建短语"添加：标题、分类（通用短语、发票与开票信息、常用地址与联系人、客服与商务话术、开发与代码片段）、触发缩写（可选）和内容。
- 内容里可以写变量：`{date}`（年-月-日）、`{time}`（时:分:秒）、`{datetime}`、`{clipboard}`（当前剪贴板文本，最多 32768 字符）。旧短语里的 `{cursor}` 会被移除，不会移动光标，因此新建表单不再列出。
- 选中短语按 Enter 粘贴到原输入位置，⌘/Ctrl+Enter 复制解析后的文本，⌘/Ctrl+E 编辑，⌘/Ctrl+Backspace 删除（删除前确认，删除后无法恢复；搜索框里有文字时这个组合键用于删除输入框文字）。
- 触发缩写只用于在列表中搜索，不会在其他应用里自动展开。
- macOS 上自动粘贴需要在"系统设置 > 隐私与安全性 > 辅助功能"中授权 ZTools，未授权时提示粘贴失败。

## 平台与要求

- 支持：Windows、macOS
- 需要客户端 1.1.8.3 或更新。

## 网络与数据

- 不联网，数据只保存在本机。
