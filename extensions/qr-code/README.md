# 二维码生成

输入网址或文字实时生成二维码，也能生成 Wi-Fi 连网二维码，可复制图片或另存为 PNG。

## 使用

- 命令：文本与链接生成二维码（关键词如 `二维码`、`qrcode`）、Wi-Fi 二维码（`wifi二维码`，打开后直接进入 Wi-Fi 表单）。
- 在输入框输入内容，右侧实时预览二维码及内容类型、字节数和版本；搜索框旁的下拉框选择纠错等级（低 7% / 中 15% / 较高 25% / 高 30%）。内容超出容量时提示缩短内容或调低纠错等级。
- `Enter` 复制二维码图片（同时记入历史），`⌘/Ctrl+Enter` 只保存到历史，`⌘/Ctrl+K` 打开动作面板（另存为 PNG、用剪贴板内容生成、生成 Wi-Fi 二维码）。历史条目上 `Enter` 复制图片，`⌘/Ctrl+Enter` 复制内容文字。
- Wi-Fi 表单填写名称、密码、加密方式（WPA/WPA2/WPA3、WEP、无密码）和是否隐藏网络，`⌘/Ctrl+Enter` 生成并保存（固定使用“中”纠错等级）；WPA 密码需 8–63 个字符（或 64 位十六进制），WEP 密码需 5 / 13 个字符（或 10 / 26 位十六进制），不合规时不生成。
- 历史最多保留 100 条，可收藏、复制内容文字、另存为 PNG、删除；单条删除不确认；清空历史前会确认，收藏的也会一起清空。

## 平台与要求

- 支持：Windows、macOS
- 客户端已内置，无需单独安装。

## 网络与数据

- 不联网，数据只保存在本机；生成历史（包括 Wi-Fi 二维码里的密码）保存在插件存储中。
