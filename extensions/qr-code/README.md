# 二维码生成器 (qr-code)

基于 ZTools 最新纯声明式 UI 架构与 Raycast 兼容组件库开发的离线极速二维码生成器。

## 功能亮点
- **零 CSS 样式与零 HTML**：完全基于 `@ztools/raycast-compat` 声明式组件构建，由宿主统一渲染 Fluent / Mica 亚克力亚态毛玻璃；
- **离线极速生成**：纯 JS 算法离线生成矢量 SVG 与 DataURL，无需联网，保护数据与隐私；
- **四级纠错等级**：支持 Low (7%)、Medium (15%)、Quartile (25%)、High (30%) 四级纠错等级调节；
- **剪贴板联动与导出**：支持一键从剪贴板创建二维码，支持一键复制 SVG 源码、文本内容或在浏览器中打开链接；
- **全键盘极客闭环**：`Enter` 激活首要动作查看详情，`Ctrl+K` 唤起操作抽屉，`Esc` 快速返回。
