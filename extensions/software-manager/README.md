# 软件卸载

列出本机系统登记的已安装软件，可启动软件自带的卸载程序；另外只读列出 AppData 下的目录占用。

## 使用

- 命令：`软件卸载`（也可输入 `应用卸载`、`uninstall`）、`大体积软件`。两个命令打开同一界面，列表都按占用体积从大到小排列。
- 左侧按名称归入 8 个分类（匹配不上的归入"其他"），顶部下拉框按安装盘符筛选。占用体积取自软件登记的估算值，可能缺失或不准；没有登记的版本、发布商、体积和安装位置显示为未知。
- 读不到系统登记的软件清单时，状态条显示失败原因，不会改用其他方式推测软件。
- 选中软件按 Enter 卸载：确认框里显示将要运行的卸载命令，确认后启动该软件自带的卸载程序，提示"卸载程序已启动"只表示已启动，是否卸载完成以卸载向导为准；Ctrl+Enter 在资源管理器中定位安装目录（软件没有登记安装目录时没有这个动作）；Ctrl+K 里还有启动软件、复制卸载命令行等动作。
- 部分系统核心组件不能卸载；卸载系统运行库前会额外警告。
- 左侧"AppData 目录"：只读列出 `%APPDATA%` 与 `%LOCALAPPDATA%` 下各前 12 个目录的占用，按目录名与已安装软件名称粗略比对，标出"名称相近"的软件或"未匹配到已安装软件"，比对可能误判。这里不提供删除，Enter 在资源管理器中定位目录，Ctrl+Enter 复制目录路径。

## 平台与要求

- 支持：仅 Windows
- Windows 实现尚待真机复核。

## 网络与数据

- 不联网，不保存数据。
