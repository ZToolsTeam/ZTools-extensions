# 测试数据生成

在本机随机生成测试用的身份证号、统一社会信用代码、银行卡号（校验位按标准算法计算）和手机号，以及批量用户 JSON。

## 使用

- 命令：测试数据（关键词如 `生成身份证`、`生成手机号`、`mock数据`）、mock json（`生成用户json`、`批量mock`）；搜索框旁的下拉框可在“单项”和“批量 JSON”之间切换。
- 单项：18 位身份证号（按 GB 11643 计算校验码）、统一社会信用代码（按 GB 32100 计算校验位）、银行卡号（Luhn 校验）、11 位手机号，以及姓名与公司名；右侧显示号码各段含义和校验算法。
- 批量：在搜索框输入 1~500 的条数（默认 10；输入无效时提示并按 10 条生成），生成用户数组，每条含编号、姓名、性别、年龄、身份证号、手机号、邮箱（`example.com` 保留域名）、公司名、信用代码、银行卡号、地址和创建时间。
- 单项：`Enter` 复制数值，`⌘/Ctrl+Enter` 换一批（也可按 `⌘/Ctrl+R`），`⌘/Ctrl+Shift+C` 复制为键值对 JSON；批量：`Enter` 复制完整 JSON，`⌘/Ctrl+Enter` 或 `⌘/Ctrl+R` 重新生成。
- 数据随机生成，只保证格式与校验位正确（手机号、姓名与公司名没有校验位），可能与真实号码、人名或企业重合，仅供开发测试使用，不得用于实名认证或冒用他人身份。

## 平台与要求

- 支持：Windows、macOS

## 网络与数据

- 不联网，数据只保存在本机。
