# 域名映射

保存多套 Hosts 方案，预览后应用到系统。以下功能与保护措施仅适用于 macOS：Mac 使用系统授权，不需要以管理员身份启动客户端。

- 新建或编辑方案只保存到本地；在方案行按 Enter 预览，再确认应用。
- 当前系统内容来自实际读取。启用状态来自系统管理区；编辑后尚未应用会显示“系统使用旧内容”。
- 系统原有内容完整保留。相同域名、同一地址族指向不同 IP 时停止，避免悄悄覆盖已有规则。IPv4 与 IPv6 可同时存在。
- 写入前保存并校验备份，确认期间原文件有变化就停止。原子交换保留被替换的原对象；备份可从“当前系统 Hosts”的动作面板查看并预览恢复。
- 写入与 DNS 刷新分别报告结果。DNS 授权取消不撤销已经写入的 Hosts；可重新刷新或通过备份恢复。
- 不读取失败后的默认方案，不覆盖损坏的本地方案。外部程序破坏管理区结构时停止合并，请先检查系统原文件。

配置文件最多 1 MiB，最多 256 个本地方案。系统授权、文件权限、只读磁盘或安全软件都可能阻止操作；界面会显示实际错误，不宣称已生效。

## 平台与要求

- 支持：仅 macOS
- 需要客户端 1.1.8.5 或更新。
- Windows 版正在重做，插件市场暂不向 Windows 提供。
