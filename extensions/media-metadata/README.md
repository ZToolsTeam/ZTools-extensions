# EXIF隐私抹除

在本机读取照片与音视频的元数据，清理照片里的定位等信息后另存新副本，原文件保持不变。

## 使用

- 命令：清除照片隐私（关键词如 `exif`、`删除gps定位`）、清除gps（`抹除照片位置`）、视频参数查看（`查看视频编码`、`音频参数`）；最后一个只查看参数，不提供清理。
- 点“选择文件”选取 JPEG、PNG、HEIC / HEIF 照片或 MP4、MOV、MP3、M4A、WAV、FLAC 音视频，列表显示类型、大小和是否检测到定位标签。
- 清理内容二选一：
  - 定位及相关附属元数据：删除 GPS 定位，同时删除 XMP、IPTC、厂商注记等可能含位置副本的信息，保留标准 EXIF 拍摄参数；
  - EXIF / XMP / IPTC：删除拍摄、作者等元数据，保留方向、色彩等显示参数。
- 照片上 `Enter` 清理并选择副本保存位置，`⌘/Ctrl+Enter` 查看读取到的全部原始参数；音视频只能查看参数。
- 保存前核对图像数据和显示参数没有变化、定位标签已清除，任一项不通过就停止保存。副本须使用与原照片同类型的扩展名，不能覆盖原文件，也不会覆盖已存在的同名文件；单个文件最大 16 MiB。
- 不处理画面内容、文件名或图片中文字里的个人信息；未识别到的字段不代表文件里不存在。

## 平台与要求

- 支持：Windows、macOS
- 需要客户端 1.1.8.5 或更新。

## 网络与数据

- 不联网，数据只保存在本机。
