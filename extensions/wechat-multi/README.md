# 微信多开

开发中，暂不在插件市场提供：客户端只会再运行一次微信程序，不能解除微信的单实例限制；微信已在运行时再启动通常只会切换到已有窗口，多开功能不成立。

再运行一次本机的微信电脑版程序，并列出正在运行的微信进程。

## 使用

- 命令：微信多开（插件主命令）。
- 第一行"再运行一次微信"：`Enter` 让客户端再运行一次微信程序。
- 启动方式是在常见安装位置和注册表登记的安装目录中找到微信程序后直接再运行一次，不修改、不注入微信程序文件，也不会解除微信自身的单实例限制。界面提示"已再次运行微信程序"只表示程序已运行，是否多开成功以是否出现新的登录窗口为准。
- 其余各行是正在运行的 WeChat / Weixin 进程，显示 PID、启动时间和内存占用；新版微信一个账号也会有多个同名进程，进程数不等于已登录的账号数。`Enter` 复制 PID。顶部状态条的"刷新"重新读取。
- 未检测到微信安装路径、读取进程失败或启动失败时显示失败原因。不在 ZTools 客户端中运行时提示需要在客户端中使用，不显示示例数据。
