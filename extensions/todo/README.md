# 待办清单

输入后回车即可添加待办，可设高 / 中 / 低优先级，按完成状态筛选。

## 使用

- 命令：待办清单（关键词如 `todo`、`待办`）。
- 在输入框输入内容按 `Enter` 直接添加（中优先级），`⌘/Ctrl+Enter` 打开新建表单（标题已填好，可选择优先级）；输入内容同时用于搜索已有待办，部分匹配的条目排在“添加”一行之后；与已有待办标题完全相同时不显示“添加”一行。
- 选中待办按 `Enter` 切换完成状态，`⌘/Ctrl+K` 打开动作面板（复制标题、删除、清空已完成）。删除和清空已完成会直接执行，不经确认。
- 搜索框旁的下拉框可筛选全部 / 进行中 / 已完成；未完成的排在前面，并按优先级从高到低排列。
- 没有编辑功能；读取数据失败或数据损坏时暂停修改，不会覆盖原数据；数据损坏时可在动作面板选择先完整备份原数据再重新开始。

## 平台与要求

- 支持：Windows、macOS
- 客户端已内置，无需单独安装。

## 网络与数据

- 不联网，数据只保存在本机。
