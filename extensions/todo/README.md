# 极简待办清单 (todo)

基于 ZTools 最新纯声明式 UI 架构与 Raycast 兼容组件库开发的待办管理工具。

## 功能亮点
- **零 CSS 样式与零 HTML**：完全基于 `@ztools/raycast-compat` 声明式组件（`<List>` 与 `<Form>`）构建，由宿主统一渲染 Fluent / Mica 亚克力亚态毛玻璃；
- **状态筛选与优先级划分**：支持“全部 / 进行中 / 已完成”下拉过滤，并高亮标记“高 / 中 / 低”三档优先级；
- **声明式表单新建**：通过 `<Form>` 规范表单提供标题输入与优先级设置，支持表单校验；
- **全键盘优先体验**：`Enter` 快速勾选/取消待办，`Ctrl+N` 呼出新建表单，`Ctrl+K` 唤起操作抽屉。
