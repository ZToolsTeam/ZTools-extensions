# 番茄倒数

25 分钟番茄专注计时，加上保存在本机的倒数日（重要日程、发薪日、上线日期等）。

## 使用

- 命令：`番茄钟`、`专注`、`倒数日`；`开始专注` 立即开始一轮，已有进行中或暂停的计时会保留；`新建倒数日` 直接打开新建表单。
- 选中番茄钟，Enter 开始、暂停或继续，⌘/Ctrl+Enter 取消当前计时。
- 每轮 25 分钟专注结束后自动进入 5 分钟短休息，每完成 4 轮改为 15 分钟长休息；休息结束后需要手动开始下一轮。
- 计时由客户端负责，离开插件页面后继续；重新打开客户端会按截止时间恢复，只结算已到期的这一轮，不会补出后续专注次数。退出客户端期间不会弹出通知。
- 顶部「新建倒数日」填写名称、日期（YYYY-MM-DD）和分类（工作、财务、生活），可设为每月循环，月末自动适配 28、29、30、31 天。倒数日按 Enter 编辑，⌘/Ctrl+Enter 复制天数摘要，删除放在 ⌘/Ctrl+K 动作面板中，执行前会确认。
- 存储读取失败时会提示并保留原记录，不会当作首次使用覆盖；倒数日在其他窗口改过时，需要刷新后再操作。

## 平台与要求

- 支持：Windows、macOS
- 需要客户端 1.1.8.5 或更新。
- 专注和休息到期时发送系统通知，能否显示取决于操作系统的通知权限和勿扰设置。

## 网络与数据

- 不联网，数据只保存在本机。
