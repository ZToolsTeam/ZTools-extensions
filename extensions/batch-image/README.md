# 图片压缩

批量压缩、缩放和转换 PNG、JPG、WebP、BMP 图片。结果另存为原图同目录下的新文件，不改动原图。

## 使用

- 命令：图片批量压缩（如 `图片压缩`、`压缩图片`）、报销/政务附件压缩（如 `300kb`、`报销附图`）、PNG/WebP/BMP 批量转 JPG（如 `转jpg`、`webp转jpg`）、扫描件转灰度（如 `扫描件转灰度`）。
- 打开后扫描图片、下载、桌面目录里的图片（每个目录最多列出 50 张）；也可以在资源管理器里「复制为路径」后，点顶部「从剪贴板添加」。
- 搜索栏右侧切换方案：常规压缩、报销/政务附件压缩、批量转 JPG、批量转 PNG、限制最长边 1920px、扫描件转灰度；左侧可再调整输出格式、画质档位（高 / 中 / 低）和尺寸约束。
- `Enter` 处理已勾选的图片；`Ctrl+Enter` 在资源管理器中显示（处理成功后显示输出文件）；`Ctrl+S` 只处理当前图片；`Ctrl+Shift+C` 复制输出文件路径（处理成功后）；`Ctrl+A` 全选或取消全选；`Delete` 把原图移入回收站（先确认）；`Ctrl+K` 打开动作面板。
- 结果另存为 `原名_opt.扩展名`，已有同名文件时改用 `_opt_2` 或带时间的文件名，不覆盖已有文件。
- 输出 JPG 会有画质损失；PNG 保持为 PNG 时，中、低档会降低色深（高档不降）。报销/政务附件方案转为 JPG、低档画质、最长边不超过 1280px，不会按目标体积反复压缩，处理后只标出仍超过 300KB 的图片。
- 保持原格式、不缩放也不转灰度时，重新编码后反而变大的图片会输出与原图相同的内容；输出不小于原图的图片都标「未变小」。
- 转 JPG 时透明区域可能变成黑色；重新编码不保留照片方向标记，部分竖拍照片输出后可能显示为横向。
- 处理 WebP 图片需要本机已安装 ffmpeg。

## 平台与要求

- 支持：仅 Windows
- 客户端已内置，无需单独安装。
