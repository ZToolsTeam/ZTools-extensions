# 目录同步

比对两个目录中普通文件的内容，把差异复制到另一边；覆盖或移入废纸篓（仅 macOS 镜像模式）之前，先保存并校验原文件备份。

## 使用

- 命令：`目录同步`、`文件夹同步`、`增量备份`、`文件夹比对`。
- 点顶部「选择目录」依次选择源目录和目标目录（两者不能相同或互相包含），在左侧选择模式，再点「重新比对」，右侧列出新增、覆盖、移入废纸篓（镜像模式）和冲突的文件。
- 单向增量：把源目录的新增和不同内容复制到目标目录。双向合并：补齐两边独有的文件；同名不同内容按修改时间判断方向，修改时间相差 2 秒以内标为冲突。镜像：另把目标目录独有的文件移入废纸篓，仅 macOS 可用（Windows 不显示该选项）。
- 空格勾选文件，Enter 执行已选项，⌘/Ctrl+Enter 在文件管理器中查看该文件。移入废纸篓的文件需要手动勾选；冲突文件不能执行，需自行处理后重新比对。
- 默认忽略 `.git`、`node_modules`、`.DS_Store`、`Thumbs.db`，可在左侧关闭。
- 执行前会重新扫描两边。比对后文件有变化、遇到链接、读取失败或备份失败都会停止，并分别显示已完成和未完成的数量；已完成的写入不会自动撤销，原文件可从备份恢复。
- 备份保存在被写入一侧目录根下的 `.ztools-sync-backups/<本次编号>/`：`backup/` 是比对时的原文件副本，`original/` 是执行中移出的原文件，`incoming/` 是尚未写入的内容。执行后可在动作面板打开备份目录，按其中的「恢复说明.txt」把文件复制回相同的相对路径。备份不会自动清理；根目录下的 `.ztools-sync-backups` 不参与同步。
- 只同步普通文件，不复制空目录；单个文件最大 2 GiB，每边最多扫描 5000 项、48 层目录。

## 平台与要求

- 支持：Windows、macOS（镜像模式仅 macOS）
- 需要客户端 1.1.8.5 或更新。
- 需要客户端带有安全文件访问组件，缺失时会提示“安全文件组件不可用”。

## 网络与数据

- 不联网，数据只保存在本机。
