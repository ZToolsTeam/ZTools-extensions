# 文件解锁

macOS 与 Windows 均不在启动时自动读取剪贴板或扫描任何目录/磁盘占用；由用户主动选择目标后，检测真实占用进程并确认操作。

## 使用

- **Windows**：
  - 顶栏与动作面板提供「选择文件检测」「选择文件夹检测」，以及手动动作「检测剪贴板中的路径」；也可直接拖入文件/文件夹或在搜索框粘贴完整路径后自动检测。
  - `usb-unlock` 入口启动时仅列出可移动磁盘与 USB/SD/MMC 移动硬盘分区供选择，不自动扫描盘内句柄占用。
  - 在目标或进程条目的动作面板中可执行「结束占用进程（解锁）」「一键全部解锁」「解锁并移入回收站」或「清空当前目标」（`Ctrl+Shift+Backspace`）。
- **macOS**：
  - 选择文件或文件夹，或粘贴完整路径（可带引号）后按 Enter，查看哪些进程正在占用；选中目标或进程条目支持「清空当前目标」（`Cmd+Shift+Backspace`）。
  - 外接磁盘入口列出系统识别到的已挂载外接磁盘，也可手动选择挂载目录。
  - 选中进程后，Enter 为普通结束，强制结束放在动作面板中；普通结束超时不会自动强制结束。结束进程可能丢失程序中尚未保存的数据，操作前会列出进程供确认。客户端在发信号前复核进程身份和占用，并在结束后重新检测。
  - 选中目标行，可以重新检测、复制路径、结束占用后移入废纸篓，或打开重命名表单。重命名只发生在原目录，遇到同名目标就停止；回收支持文件和非空文件夹，可从访达的废纸篓恢复。仍有占用、扫描失败、目标被替换、符号链接或硬链接、系统关键目录、磁盘根目录及客户端数据目录都会停止相应操作。

检测结果只代表当前权限可见的进程。文件夹扫描不跟随符号链接，不跨越嵌套挂载卷；扫描失败不会显示成“没有占用”。“未发现占用”不是可以安全弹出磁盘的保证，弹出磁盘请使用安全弹出或访达。

## 平台与要求

- 支持：Windows、macOS
- 需要客户端 1.1.8.5 或更新。
- macOS 需要客户端带有文件解锁能力和原生文件访问组件。
- Windows 实现尚待真机复核。
