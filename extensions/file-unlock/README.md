# 文件解锁

macOS：选择文件或文件夹，或粘贴完整路径后按 Enter，查看哪些进程正在占用。外接磁盘入口列出系统识别到的已挂载外接磁盘，也可手动选择挂载目录。

Windows：粘贴完整路径后自动检测，暂不提供文件选择窗口；外接磁盘入口列出可移动磁盘，以及接在 USB、SD 或 MMC 总线上的移动硬盘分区，读取失败时显示原因。以下说明除特别标注外适用于 macOS。

macOS 使用系统真实占用信息。选中进程后，Enter 为普通结束，强制结束放在动作面板中；普通结束超时不会自动强制结束。结束进程可能丢失程序中尚未保存的数据，操作前会列出进程供确认。客户端在发信号前复核进程身份和占用，并在结束后重新检测。

选中目标行，可以重新检测、复制路径、结束占用后移入系统回收站，或打开重命名表单。重命名只发生在原目录，遇到同名目标就停止；回收支持文件和非空文件夹，可从 Finder 废纸篓恢复。仍有占用、扫描失败、目标被替换、符号链接或硬链接、系统关键目录、磁盘根目录及客户端数据目录都会停止相应操作。

检测结果只代表当前权限可见的进程。文件夹扫描不跟随符号链接，不跨越嵌套挂载卷；扫描失败不会显示成“没有占用”。“未发现占用”不是可以安全弹出磁盘的保证，弹出磁盘请使用 Finder。

## 平台与要求

- 支持：Windows、macOS
- 需要客户端 1.1.8.5 或更新。
- macOS 需要客户端带有文件解锁能力和原生文件访问组件。
- Windows 实现尚待真机复核。
