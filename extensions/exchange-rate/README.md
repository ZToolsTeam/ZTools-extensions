# 汇率计算

输入金额即可看到它在其他币种下的金额，支持 15 种主流法币以及黄金（盎司）、比特币。

## 使用

- 搜索框右侧下拉选择源币种（默认人民币），会记住你的选择。
- 在搜索框输入金额，列表给出换算到其他币种的结果；行右侧显示反向单位汇率（如 `1 USD = 7.1234 CNY`）。
  - `100`：按当前源币种换算；`0` 是合法金额，结果为 0。
  - `100 USD`：临时以美元为源币种。
  - `100 USD to CNY`（也可写 `到`、`转`、`=`）：只显示目标币种。
  - 输入币种代码、中文名或别名（如 `日元`、`gold`、`比特币`）可筛选币种。
- 选中某个币种：`Enter` 复制换算结果（纯数字），`⌘/Ctrl+Enter` 复制换算等式（如 `100 CNY = 14.04 USD`），`⌘/Ctrl+K` 打开动作面板，可「以该币种为源币种」（把换算结果作为新的金额）或收藏。
- `⌘/Ctrl+D` 收藏 / 取消收藏，收藏的币种置顶显示；顶部状态条的「刷新汇率」跳过缓存重新获取。
- 金额小数位：日元、韩元 0 位，比特币 8 位，黄金 4 位，其余 2 位。

## 网络与数据

插件经客户端发送两个只读 GET 请求，金额与币种只在本机换算，不发送给任何服务：

| 域名 | 请求 | 用途 |
| --- | --- | --- |
| `open.er-api.com` | `https://open.er-api.com/v6/latest/USD` | 以美元为基准的法币汇率表（数据源 ExchangeRate-API，每日更新） |
| `api.coingecko.com` | `https://api.coingecko.com/api/v3/simple/price?ids=bitcoin,tether-gold&vs_currencies=usd` | 比特币与黄金的美元价格；黄金价格取 Tether Gold（XAUT，1 枚对应 1 金衡盎司黄金）的报价，与现货金价可能存在小幅偏差 |

- 汇率保存在本机缓存，30 分钟内再次打开直接使用缓存，状态条标注缓存时间；超过 30 分钟自动联网更新。
- 法币汇率请求失败时显示错误，不用估算或示例数据代替；若本机有 7 天内的缓存，会继续显示并在状态条标注「刷新失败」及缓存获取时间。
- 比特币或黄金报价获取失败时，对应币种显示「暂无报价」，其余汇率照常使用。
- 源币种与收藏保存在本机插件存储中；读取失败时不会覆盖已保存的设置。

## 权限

- `network`：请求上表两个域名获取汇率与报价。
- `clipboard`：复制换算结果。

## 平台

- Windows、macOS

## 与 1.x 版本的差异

2.0 用声明式界面重写：去掉旧版的双输入框与独立的「常用行情」侧栏，改为「输入金额 → 一次列出所有币种」的列表；收藏从「货币对」改为「目标币种」。旧版保存在客户端数据库中的设置不会自动迁移，首次使用需重新选择源币种与收藏。
