# 视频下载

开发中，暂不在插件市场提供：客户端没有视频解析能力：B 站、抖音、快手、YouTube、微博等平台链接无法下载，插件只能复制 yt-dlp 命令让用户自行下载；目前只有 .mp4 等视频直链能下载（单个文件不超过 1 GiB，需在 5 分钟内下完）。等客户端提供视频解析下载能力并在 Windows 上实测通过后再发布。

识别剪贴板或搜索框里的视频链接（B 站链接与 BV 号、抖音、快手、YouTube、微博，其他链接按通用链接处理）。视频直链可以下载到本机；平台链接只能生成 yt-dlp 命令，由你自己运行。同时管理「视频」和「下载」文件夹里已有的视频文件。

## 使用

- 命令：视频下载（插件主命令）。
- 打开时读取剪贴板里的分享文本并提取链接；也可以把链接或 BV 号粘贴到搜索框。复制了新链接后点"重新扫描"即可重新读取。
- 左侧第一行"当前链接"显示识别结果。链接以 .mp4、.webm、.mkv、.mov、.flv、.m4v 结尾时，`Enter` 弹出保存对话框，选好位置后由客户端下载（同名文件由系统对话框确认是否替换）；单个文件不超过 1 GiB，5 分钟内没下完会报错。
- 其他链接（平台页面、M3U8 等）按 `Enter` 只会把 yt-dlp 命令复制到剪贴板，插件不下载。需要自己安装 yt-dlp（合并音视频、转换音频还需要 FFmpeg）并在终端里运行这条命令。
- 搜索框右侧选择 yt-dlp 命令的档位：最高可用画质、不超过 1080P、不超过 720P、仅音频 MP3、仅音频 FLAC、不超过 1080P 加字幕与封面。档位只影响复制的命令，视频直链按原文件下载。
- 左侧各行上 `Ctrl+Enter` 打开「视频」文件夹；视频直链也可以在 `Ctrl+K` 里复制 yt-dlp 命令。
- 右侧列出「视频」和「下载」文件夹里已有的视频（mp4、mkv、mov、webm、flv、avi），每个文件夹最多 180 个。选中视频按 `Enter` 用系统默认播放器打开，`Ctrl+Enter` 在资源管理器中定位。
- 勾选视频后，`Ctrl+K` 中出现"移入回收站"，只处理已勾选的视频，执行前会再确认一次；扫描后不会自动勾选。移入失败的文件会逐个列出原因，并保持勾选。

## 平台与要求

- 支持：仅 Windows

## 网络与数据

- 插件只把你输入或复制的视频直链交给客户端下载，不请求其他地址；平台链接不会发出任何请求，只写进复制的 yt-dlp 命令（BV 号转换成 `www.bilibili.com` 的视频页地址）。
- 剪贴板内容只用于识别视频链接。
