# 主机与代理

读取本机 SSH 配置里的主机别名，在终端中连接或建立本地端口转发；查看和修改 Git、NPM 用户配置中的代理，或打开一个带代理环境变量的新终端。

## 使用

- 命令：`ssh`（也可输入 `主机管理`、`代理管家`）；只看代理：`切换代理`、`终端代理`；端口转发：`端口转发`、`ssh隧道`
- 主机列表来自 SSH 配置文件及其 Include 文件里明确写出的 Host 别名，通配符规则不单独列出；只读取配置，不读取私钥内容。配置文件位置：
  - Windows：`%USERPROFILE%\.ssh\config`，系统级配置 `%ProgramData%\ssh\ssh_config`
  - macOS：`~/.ssh/config`
- 选中主机按 Enter 在新终端中连接，⌘/Ctrl+Enter 建立本地端口转发（用 `端口转发` 命令打开时两者对调），⌘/Ctrl+K 里可复制连接命令。端口转发只在本机 127.0.0.1 监听，终端保持打开期间有效，按 Ctrl+C 结束。
- Git、NPM 代理：可设置本机 HTTP 代理端口或清除代理。写入前显示修改前后的对比并需要确认，先备份原文件，写入后读回核验；在顶部下拉框切到"修改备份"可预览并恢复原配置。只修改界面中列出的用户配置文件，项目配置或环境变量可能覆盖它。
- 新终端代理：打开一个设置了代理环境变量的新终端窗口，已打开的终端不受影响。插件不会替你启动代理软件。
- macOS 用"终端"应用打开连接；Windows 使用系统自带的 OpenSSH 客户端（`System32\OpenSSH\ssh.exe`），未安装时提示到"设置 > 系统 > 可选功能"安装，修改 Git 代理需要已安装 Git for Windows。
- 读取或设置失败时显示实际原因，不会假装已生效。

## 平台与要求

- 支持：Windows、macOS
- 需要客户端 1.1.8.5 或更新。
- Windows 实现尚待真机复核，不同终端环境、代理软件与 Git 配置下的表现可能有差异。

## 网络与数据

- 插件本身不发网络请求；SSH 连接和端口转发由系统 ssh 在终端中进行，连接的是你配置的主机。
- 修改 Git、NPM 配置前的备份保存在本机。
