# 解压与压缩

不用先解压就能查看本机 ZIP 压缩包里的文件，可以整包解压，也可以只提取勾选的文件。

## 使用

- 命令：查看压缩包（关键词如 `解压`、`zip`）、提取压缩包内办公文档。两个命令打开同一界面，“提取压缩包内办公文档”打开后默认筛选办公文档；左栏的“解压前检查”显示解压位置，以及是否有越界路径、是否含加密条目。
- 打开后扫描“下载”“桌面”“文档”目录中的 `.zip` 文件，用搜索框旁的下拉框切换压缩包；左栏按文件类型筛选，右栏按解压后大小列出包内文件，可按文件名、路径或 CRC32 搜索。文件名自动识别 UTF-8 与 GBK 编码。找不到压缩包或读取失败时，右栏直接显示原因。
- 在右栏文件上按 `Enter`：没有勾选时整包解压，有勾选时只提取勾选的文件；`Ctrl+Enter` 在资源管理器中定位压缩包，`Ctrl+S` 只提取当前文件，`Ctrl+K` 打开动作面板（校验、复制包内路径、移入回收站等）。
- 整包解压：包内只有一个顶层文件夹时直接解压到压缩包所在目录，否则解压到压缩包旁的同名文件夹；提取所选文件时放到同名文件夹并保留包内路径。解压前会确认目标文件夹，目标位置已有同名文件会被覆盖。
- 含 `../` 或绝对路径的条目会被标出并拒绝提取；含加密条目的压缩包暂不支持解压，会直接提示。
- “校验”读取压缩包目录、检查越界路径和加密条目，并计算整个文件的 SHA-256，不逐个解压校验各文件的 CRC32。
- 把原压缩包移入回收站前会确认。
- 目前只支持 ZIP，不支持 7Z、RAR、TAR，也不提供压缩打包。

## 平台与要求

- 支持：仅 Windows
- 客户端已内置，无需单独安装。

## 网络与数据

- 不联网，数据只保存在本机。
