# 发票助手

扫描下载、桌面、文档目录里的 PDF / XML 电子发票，识别发票号码、开票日期、销售方、购买方、价税合计与税额，做发票号查重和购方抬头检查，并导出报销明细。

## 使用

- 命令：电子发票汇总与导出报销明细（如 `发票报销`、`报销台账`）、按模板复制规范命名的电子发票副本（如 `发票重命名`）、差旅交通与住宿发票筛选（如 `差旅发票`、`打车票`）。
- 识别不到的字段标为「未识别」，开票日期与当天相同时标为「待核对」；这类发票不能勾选导出，要先按 `Ctrl+I` 在表单里补全或核对。
- 发票号码与列表中前面某张相同的发票标为重复，不能勾选；购买方含「个人」「先生」「女士」或没有中文时标为抬头异常，默认不勾选。
- 搜索栏右侧选择命名模板（4 种，按分类、日期、销售方、金额、发票号组合）。
- `Enter` 生成报销归档：复制按模板命名的发票副本，并生成报销明细 CSV（字段不全的发票按 `Enter` 先打开补全表单）。
- `Ctrl+Enter` 复制已选发票的报销明细（制表符分隔，可直接粘贴到表格）；`Ctrl+E` 只导出报销明细 CSV；`Ctrl+T` 切换费用分类；`Ctrl+Shift+C` 复制当前发票信息；`Ctrl+O` 在资源管理器中定位原发票；`Delete` 把发票原件移入回收站（先确认）；`Ctrl+K` 打开动作面板。
- 每次导出在第一张发票所在目录下新建 `ZTools_Reimbursement_Export\报销归档_<时间>` 目录，副本和 CSV 都写在里面；原发票不改动，同批重名的副本依次加 `_2`、`_3`。
- 部分文件读取或识别失败时提示数量，左侧「读取失败的文件」可复制失败文件与原因。
