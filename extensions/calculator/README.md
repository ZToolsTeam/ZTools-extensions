# 极简即时计算器 (calculator)

基于 ZTools 最新纯声明式 UI 架构与原生声明式组件库开发的极速计算器。

## 功能亮点
- **零 CSS 样式与零 HTML**：完全基于 `@ztools/declarative-ui` 声明式组件构建，由宿主统一渲染 Fluent / Mica 亚克力亚态毛玻璃；
- **实时即时求值**：在搜索栏输入数学算式（如 `128 * 4 + 16`、`sqrt(144)`、`2^10`、`sin(30)`），首行即刻显示高精度结果；
- **全键盘极客闭环**：`Enter` 复制计算结果并加入历史，`Ctrl+K` 唤起操作抽屉；
- **安全健壮的数学引擎**：无需 `eval`，语法容错、除零防护与溢出保护。

## 每日汇率与网络权限

汇率换算需要 `network` 权限，仅通过宿主向 `open.er-api.com` 发送固定 GET 请求：`https://open.er-api.com/v6/latest/USD`，获取美元基准的每日汇率表。计算金额、目标币种和其他用户输入均在本地处理，不发送给汇率服务。

界面显示数据来源与服务返回的更新时间，汇率缓存到下一次更新。网络失败、响应无效或缓存过期时明确提示错误，不使用固定汇率冒充最新数据。汇率仅作换算参考，实际交易以服务机构报价为准。普通算式、单位换算和人民币大写转换无需联网。

数据来源：[ExchangeRate-API](https://www.exchangerate-api.com/)。
