# 计算器

输入算式即时出结果，也能做单位与进制换算、日期推算和颜色值转换；汇率换算与人民币大写金额转换在单独的界面里。

## 使用

- 命令：单位换算（长度、重量、存储、温度）、汇率换算、人民币大写金额转换；可输入 `单位换算`、`汇率`、`大写金额` 等关键词打开。
- 算式示例：`128 * 4 + 16`、`2 ^ 16`、`sqrt(65536)`、`sin(pi / 2)`（三角函数按弧度计算）；换算示例：`10km to miles`、`32px to rem`、`255 to hex`、`now + 2 weeks`；输入 `#3B82F6` 或 `rgb(59, 130, 246)` 列出 HEX、RGB、HSL、CMYK 写法。
- 在计算结果上按 `Enter` 复制结果并记入计算历史，`⌘/Ctrl+Enter` 粘贴到前台应用（同样记入历史）；历史条目上 `Enter` 复制、`⌘/Ctrl+Enter` 粘贴；颜色结果按 `Enter` 复制所选写法。`⌘/Ctrl+K` 打开动作面板（置顶、删除历史，进入汇率换算、人民币大写）。
- 汇率换算按 `100 USD to CNY` 输入三位币种代码；人民币大写最多两位小数、不做四舍五入，最大 999999999999.99 元。
- 日期推算：`2026-01-31 + 1 month` 这类目标月没有该日的，取当月最后一天（2026-02-28）；小时、分钟按实际经过时间计算，夏令时跳过的本地时刻会提示不存在。
- 不使用 `eval`；语法错误、除零与溢出会显示错误，不给出结果。
- 计算历史保存最近 100 条（置顶的不计入），列表中显示最近 15 条。

## 平台与要求

- 支持：Windows、macOS
- 客户端已内置，无需单独安装。

## 网络与数据

- 只有汇率换算联网：经客户端向 `open.er-api.com` 发送 GET 请求（`https://open.er-api.com/v6/latest/USD`），获取以美元为基准的每日汇率表。金额和币种在本地换算，不发送给该服务。
- 汇率缓存在本机：未到服务给出的下次更新时间时直接使用；已过期时先显示旧汇率并标注来源更新时间，同时在后台刷新。没有可用缓存且请求失败时显示错误，不用估算值代替。
- 汇率换算界面里的“打开汇率来源”会在浏览器中打开 `https://www.exchangerate-api.com`（数据来源 ExchangeRate-API）。
- 其余计算不联网，计算历史只保存在本机。
