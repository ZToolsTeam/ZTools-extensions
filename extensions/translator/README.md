# 多语言即时翻译 (translator)

基于 ZTools 最新纯声明式 UI 架构与原生声明式组件库开发的多语言即时翻译工具。

## 功能亮点
- **零 CSS 样式与零 HTML**：完全基于 `@ztools/declarative-ui` 声明式组件构建，由宿主统一渲染 Fluent / Mica 亚克力亚态毛玻璃；
- **自动语种识别**：输入中文自动译为英文，输入外语自动译为中文，支持中、英、日、韩、法、德等多语种；
- **词典与音标释义**：单词自动识别并展示音标、词性划分与例句对照；
- **翻译历史记录**：自动持久化近期翻译内容，全键盘快速回溯与一键复制。
