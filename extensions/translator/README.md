# 划词翻译

把输入或粘贴的文字交给客户端的翻译接口翻译，并给出 camelCase、snake_case 变量命名写法。

## 使用

- 命令：中英互译（关键词如 `翻译`、`translate`）、词典（`词典`、`查词`）、变量命名（`变量命名`、`驼峰命名`）。前两个命令打开同一界面；变量命名命令把 camelCase 写法作为标题和主动作。
- 在输入框输入或粘贴文字即开始翻译：输入含中文时译为英语，其余译为中文，没有其他语种可选。输入框为空时只显示输入提示。
- 每次翻译列出一行译文，右侧显示译文、原文，以及英文的 camelCase、snake_case 写法。
- `Enter` 复制译文，`Ctrl+Enter` 复制原文与译文，`Ctrl+K` 打开动作面板（含复制 camelCase、snake_case 变量名）；工具栏的“翻译剪贴板”读取剪贴板文字填入输入框后翻译。变量命名命令里 `Enter` 复制 camelCase，`Ctrl+Enter` 复制 snake_case；输入已是英文时直接转换，不经过翻译。
- 翻译接口目前只查客户端内置的离线词库，只收录少量中英常用词和办公短语。未收录或接口出错时，列表显示“未能翻译”和客户端返回的原因，不显示旧的译文。
- 列表下方显示最近的翻译记录（最多 15 条），记录由客户端保存在内存中，重启客户端后清空；插件里不能清空记录。

## 平台与要求

- 支持：仅 Windows
- 客户端已内置，无需单独安装。

## 网络与数据

- 不联网：翻译经客户端的翻译接口完成，当前只查本机离线词库，不向任何在线翻译服务发送内容。
