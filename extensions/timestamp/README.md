# 时间戳转换助手 (timestamp)

基于 ZTools 最新纯声明式 UI 架构与原生声明式组件库开发的时间转换工具。

## 功能亮点
- **零 CSS 样式与零 HTML**：完全基于 `@ztools/declarative-ui` 声明式组件构建，由宿主统一渲染 Fluent / Mica 亚克力亚态毛玻璃；
- **智能双向解析**：输入 10 位/13 位时间戳或日期文本（如 `2026-10-12 15:30:00`），实时转换为多种时间格式；
- **多时区与相对时间**：支持本地时区、北京时间、UTC 标准时间以及友好相对时间（如“刚刚”、“3小时前”）；
- **留空即实时**：不输入内容时显示当前时间并每秒刷新，复制取按下那一刻的值；
- **严格解析不编造**：只识别秒/毫秒时间戳、`2024-01-31 08:00:00`（`-` `/` `.` 年月日分隔，可带毫秒与时区）、ISO 8601、RFC 2822、`Date#toString`、美式 `12/25/2023`，其余内容（如 `abc 1`、`Oct 21`）和不存在的日期一律提示解析错误；
- **极客全键盘操作**：上下键切换条目，`Enter` 一键复制，`⌘/Ctrl+Enter` 刷新为当前时间。
