# 时间戳转换

秒 / 毫秒时间戳与日期文本互转，附带世界时钟与时区换算。

## 使用

- 命令：时间戳转换（关键词如 `时间戳`、`毫秒转日期`）、世界时钟（`世界时钟`、`时区转换`）。
- 输入时间戳或日期文本（如 `2026-10-12 15:30:00`），实时列出秒和毫秒时间戳、本地时间、北京时间（UTC+8）、ISO 8601（UTC）与相对时间（如“3 小时前”）。绝对值小于 10^11 的数字按秒处理，否则按毫秒。
- 不输入内容时显示当前时间并每秒刷新，复制时取按下那一刻的值。
- 严格解析：只识别秒 / 毫秒时间戳、`2024-01-31 08:00:00`（`-` `/` `.` 或“年月日”分隔，可带毫秒与时区）、ISO 8601、RFC 2822、`Date#toString`、美式 `12/25/2023`；其余内容（如 `abc 1`、`Oct 21`）、不存在的日期和 1970–2200 年以外的时间一律提示解析错误。
- 上下键切换条目，`Enter` 复制当前条目；在秒、毫秒、本地时间三行上按 `⌘/Ctrl+Enter` 清空输入、恢复为当前时间。
- 世界时钟：可从“世界时钟”命令或动作面板（`⌘/Ctrl+K`）进入。默认列出常用城市，搜索可查任意 IANA 时区；`Enter` 复制该地当地时间；下拉框选择时差参考时区，“换算指定时间…”可按某一时刻对照各地时间。

## 平台与要求

- 支持：Windows、macOS
- 客户端已内置，无需单独安装。

## 网络与数据

- 不联网，数据只保存在本机。
