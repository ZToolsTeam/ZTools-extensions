# 文本排版

对一段文本做中英文混排加空格、中英文标点互转、全半角转换、大小写与命名风格转换、按行去重排序和简繁转换。一次列出 24 种转换结果，选中一种在右侧预览并复制。

## 使用

- 命令：文本排版（插件主命令）。
- 第一行是待排版文本：`Enter` 打开多行编辑框（`⌘/Ctrl+Enter` 应用），`⌘/Ctrl+Enter` 从剪贴板粘贴；没有输入时用示例文本演示。搜索框只用来筛选转换方式，例如输入"大写""行号""繁体"。
- 结果行：`Enter` 复制该结果；`⌘/Ctrl+Enter` 把该结果设为新的待排版文本，可以连续套用多种转换；`⌘/Ctrl+K` 打开动作面板。
- 右侧预览最多显示前 10000 个字符，复制得到的是完整结果；转换对当前文本没有输出时不会复制空内容。
- 驼峰 / 下划线 / 短横线命名按行转换（每行一个标识符），识别 `userName`、`HTTPServer` 这类大小写边界；中文和标点不进入标识符，整段没有英文单词时显示“无输出”。
- 英文标点转中文标点时跳过行内代码、网址和邮箱；Markdown 排版不改动代码块里的内容。
- 简繁转换使用 OpenCC 词典数据，简转繁按台湾正体用字，数据来源见 THIRD_PARTY_NOTICES.md。

## 平台与要求

- 支持：Windows、macOS

## 网络与数据

- 不联网，文本只在本机处理，不保存。
