# 日程日历

在 ZTools 里记录和查看日程，用浏览器打开日程里的视频会议链接，并可导出为 ICS 日历文件。

## 使用

- 命令：在启动框搜索“日程日历”打开。
- 顶部下拉框筛选：全部日程（今天起）、即将开始（24 小时内）、含视频会议链接、历史日程。搜索框可按标题、地点、备注、日历名搜索，标题也可以用拼音搜索（“即将开始”筛选下不支持拼音）。
- Enter：有会议链接时用浏览器打开会议，否则复制日程摘要；⌘/Ctrl+Enter：有会议链接时复制链接，否则把这条日程导出为 ICS 文件；⌘/Ctrl+K：打开动作面板。
- ⌘/Ctrl+N 新建日程；⌘/Ctrl+E 把当前列表导出为 ICS 文件；⌘/Ctrl+R 重新读取；⌘/Ctrl+C 复制日程摘要；⌘/Ctrl+Shift+Backspace 删除日程（需确认，删除后不能恢复）。动作面板里还可以把列表复制为 ICS 文本。
- 新建日程需填写主题、日期（`YYYY-MM-DD`）、开始和结束时间（`HH:MM`）；跨天日程的结束时间写成 `YYYY-MM-DD HH:MM`。会议链接只接受 http / https 网址，没写协议时自动补 `https://`。
- 日程保存在客户端的本机数据库里，不读取也不写入系统日历（如 macOS 日历、Outlook）。每次最多加载 500 条，超出时状态栏会提示。
- 读取失败时会提示原因并保留上次的列表，用 ⌘/Ctrl+R 重试（列表为空时直接按 Enter）。

## 平台与要求

- 支持：Windows、macOS

## 网络与数据

- 插件本身不联网，日程只保存在本机；“加入视频会议”会用系统浏览器打开日程里的会议链接。
