# 磁盘空间分析

显示各分区的容量与已用空间，找出常用文件夹和分区里的大文件，按文件类型、后缀和目录查看，并可把文件移入回收站。

## 使用

- 命令：在启动框搜索“磁盘空间分析”打开。
- 扫描各分区根目录，以及下载、文档、桌面、视频（macOS 为影片）、系统临时文件夹（macOS 另加 `~/Library/Caches`；临时文件夹需要客户端提供常用目录接口，旧客户端上不扫描），每个位置最多取 100 个较大的文件。扫描达到条目上限时，大文件列表标为“抽样”，不代表全部文件；某个位置读取失败（例如 macOS 上拒绝了“文稿 / 桌面 / 下载”的访问、外接卷不可读）时，其余位置照常显示，失败的位置及原因列在左侧“未能扫描的目录”里；所有位置都失败才算扫描失败，状态栏显示原因。
- 左侧可按分区、10 类文件类型和热点大目录筛选，右侧大文件列表按体积从大到小排列，可勾选。
- Enter：把选中文件移入回收站（需确认）；⌘/Ctrl+Enter：在资源管理器（macOS 为访达）中定位；⌘/Ctrl+K：打开动作面板，可用默认程序打开、只看同后缀文件、批量清理已勾选的文件、复制路径。
- 系统目录，以及应用程序、照片 / iMovie / Final Cut 图库、虚拟机等“包”内部的受保护位置的文件不能勾选或移除，Enter 改为定位。
- 文件只移入回收站（废纸篓），可以还原；被占用或没有权限时提示移除失败。

## 平台与要求

- 支持：Windows、macOS
- 需要客户端 1.1.8.3 或更新。“在资源管理器 / 访达中打开此分区”需要比 1.1.8.6 更新的客户端，旧客户端上会提示升级，其余功能不受影响。

## 网络与数据

- 不联网，数据只保存在本机。
