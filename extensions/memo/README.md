# 便签

随手记录文字便签，正文支持 Markdown，可加标签，按标题、正文或标签搜索。

## 使用

- 命令：便签（关键词如 `memo`、`便签`、`笔记`）。
- 输入文字搜索便签，按最近修改排序；没有匹配时按 `Enter` 打开新建表单，并以输入内容作为标题。
- 选中便签后右侧按 Markdown 显示正文：`Enter` 复制正文，`⌘/Ctrl+Enter` 编辑，`⌘/Ctrl+K` 打开动作面板（新建、复制标题、删除）。删除前会确认。
- 编辑表单里 `⌘/Ctrl+Enter` 保存，`Esc` 返回；标题和正文不能都为空，标题留空时保存为「无标题便签」。
- 保存失败会提示原因，不会显示为已保存；存储的数据损坏时停止保存，可选择先备份原数据再重新开始。

## 平台与要求

- 支持：Windows、macOS
- 客户端已内置，无需单独安装。

## 网络与数据

- 不联网，数据只保存在本机。
