# 网页快开

保存常用网址和搜索链接，在搜索框里用"别名 + 关键词"直接打开，也可以一次打开一组网页。

## 使用

- 命令：`网页快开`（也可输入 `快捷链接`、`wk`）；只看搜索链接：`聚合搜索`；只看网址组：`打开网址组`；新建：`添加快捷链接`
- 网址里可以写 `{query}` 占位符。在搜索框输入"别名 + 空格 + 关键词"（例如 `gh react`）后按 Enter，会用关键词替换占位符再打开；不带关键词时打开该站点首页。
- 选中条目按 Enter 用系统默认浏览器打开（网址组会依次打开组内全部网页），⌘/Ctrl+Enter 编辑，⌘/Ctrl+K 里可复制网址模板（搜索链接复制的是带 `{query}` 的原模板）。
- 预置了 GitHub、知乎、B 站搜索、DeepSeek 和一个示例网址组。顶部"新建快开"可填写名称、网址、别名和备注；目前只能新建单个链接，不能新建网址组，也没有删除单条链接的动作。
- 顶部"恢复默认预设"会直接用预置列表替换全部已保存的链接，没有确认步骤。
- 只接受 http(s) 网址或域名，`javascript:` 等脚本地址会被拒绝。

## 平台与要求

- 支持：Windows、macOS

## 网络与数据

- 插件本身不发网络请求，只把网址交给系统默认浏览器打开；快捷链接只保存在本机。
