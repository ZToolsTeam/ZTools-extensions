# 多线程下载

开发中，暂不在插件市场提供：多线程分块下载需要用户自行安装并运行 aria2（开启 RPC、不设密钥、允许跨域），插件和客户端都不提供；没有 aria2 时只能单连接下载 HTTP 链接（单个文件不超过 1 GiB，需在 5 分钟内下完），FTP 与磁力链接无法下载。等客户端提供多线程下载能力并在 Windows 上实测通过后再发布。

把剪贴板或搜索框里的下载链接交给本机运行的 aria2 按所选线程数下载；没有 aria2 时，HTTP / HTTPS 链接由客户端单连接下载。同时列出本机“下载”文件夹里的文件，可按类型筛选、打开、定位或移入回收站。

## 使用

- 命令：多线程下载。
- 打开时扫描“下载”文件夹，左侧按安装包、压缩包、音视频、镜像、文档等分类，右侧列出文件；搜索框里输入的不是链接时按文件名搜索。
- 插件读取剪贴板和搜索框里的 HTTP / HTTPS / FTP / 磁力链接，显示在左侧第一行“当前链接”。复制了新链接后点“重新扫描”即可重新读取。
- “当前链接”上按 `Enter` 发起下载：
  - 本机 aria2 的 RPC 服务（`127.0.0.1:6800`）可用时，任务交给 aria2，按搜索框旁的线程档位（16 / 8 / 4 / 1）下载到“下载”文件夹，进度请在 aria2 中查看。aria2 需要以 `--enable-rpc --rpc-allow-origin-all` 启动，且不能设置 RPC 密钥，否则会提示 aria2 拒绝了任务。
  - 连不上 aria2 时，HTTP / HTTPS 链接会弹出保存对话框，选好位置后由客户端单连接下载（同名文件由系统对话框确认是否替换），线程档位不生效；单个文件不超过 1 GiB，5 分钟内没下完会报错。FTP 和磁力链接会直接提示需要 aria2。
- “当前链接”上 `Ctrl+Enter` 打开下载文件夹，`Ctrl+K` 中可以复制对应的 aria2c 命令，自己在终端里运行。
- 右侧文件上：`Enter` 打开文件，`Ctrl+Enter` 在资源管理器中定位，`Ctrl+K` 打开动作面板（勾选、移入回收站）。左侧“全部已下载文件”和其他分类上：`Enter` 只看该分类，`Ctrl+Enter` 打开下载文件夹。
- 扫描后不会自动勾选文件。勾选后 `Ctrl+K` 中出现“移入回收站”，只处理已勾选的文件，执行前会再确认一次；移入失败的文件会逐个列出原因，并保持勾选。
- 状态栏显示 aria2 是否已连接和下载盘剩余空间，剩余空间不足 10% 时会在“当前链接”上标红提示。

## 平台与要求

- 支持：仅 Windows

## 网络与数据

- 打开插件时会向本机 `http://127.0.0.1:6800/jsonrpc` 发送请求，检测 aria2 是否在运行；发起下载时把链接提交给这个地址。
- 连不上 aria2 时，只请求你粘贴或复制的 HTTP / HTTPS 下载链接，不访问其他地址。
