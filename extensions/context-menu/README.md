# 右键菜单管理

列出资源管理器中文件、文件夹和文件夹空白处右键菜单里的命令项（注册表 shell 子键），可逐项启用或禁用，并可切换 Windows 11 经典右键菜单。

## 使用

- 命令：右键菜单管理（插件主命令）。
- 扫描当前用户（HKCU）与系统级（HKLM）的 `*\shell`、`Directory\shell`，以及当前用户的 `Directory\Background\shell`；每个位置最多列出 40 项，达到上限时状态条提示可能未列全。不包含外壳扩展（shellex）。
- 搜索栏右侧按位置筛选：所有文件、文件夹、文件夹空白处、已禁用。
- `Enter` 启用或禁用当前菜单项（写入或删除注册表 `LegacyDisable` 值，修改后读回确认）；`Ctrl+Enter` 复制注册表路径；`Ctrl+Shift+C` 复制执行命令（有命令时）；`Ctrl+K` 打开动作面板。
- 状态未识别的项不能启用或禁用，此时 `Enter` 改为复制注册表路径。
- 修改系统级（HKLM）菜单项需要以管理员身份运行 ZTools，否则提示失败。
- 「Windows 11 右键菜单模式」一项可切换为经典完整菜单或恢复默认，只在 Windows 11 有效，切换后需重启资源管理器或重新登录才生效；切换前当前模式显示为「未识别」。
- 读取失败时显示失败原因，不会显示成空列表。

## 平台与要求

- 支持：仅 Windows
- Windows 实现尚待真机复核。

## 网络与数据
