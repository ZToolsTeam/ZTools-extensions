# 密码保险箱

在本机加密保存账号密码、API Key、服务器密码和软件激活码等凭据；复制密码后 30 秒自动清除剪贴板。

## 使用

- 命令：密码保险箱（关键词如 `账号密码`、`password vault`）、随机密码（`生成密码`、`密码生成器`）；用第二个命令打开并解锁后，“新建凭据”会预先填入一个随机密码。
- 首次使用需设置至少 8 位的主密码，之后每次打开都要输入主密码解锁。主密码不会保存，忘记后无法解密保险箱。
- 主密码经 PBKDF2-SHA256（60 万次迭代）派生密钥，全部条目以 AES-256-GCM 加密后保存在本机。条目分为网站与应用账号、API Key 与访问令牌、服务器与数据库密码、软件激活码与备忘四类，可按分类筛选，按标题、用户名、网址或备注搜索。
- 条目上：`Enter` 复制密码，`⌘/Ctrl+Enter` 复制用户名（没有用户名时为显示或隐藏明文），`⌘/Ctrl+H` 显示或隐藏明文，`⌘/Ctrl+G` 生成 20 位随机密码并复制，`⌘/Ctrl+Backspace` 删除条目（删除前需确认，删除后无法恢复），`⌘/Ctrl+K` 打开动作面板（编辑等）。
- 复制的密码和随机密码 30 秒后由客户端自动从剪贴板清除，也不会记入客户端的剪贴板历史；复制用户名不会自动清除。
- 顶部“立即锁定”会清除内存中的主密码和已解密的条目。
- 随机密码为 20 位，包含大小写字母、数字和符号，不含 0、O、1、l、I 等易混淆字符。

## 平台与要求

- 支持：Windows、macOS
- 需要客户端 1.1.8.5 或更新。

## 网络与数据

- 不联网，保险箱只以密文形式保存在本机。
