# 垃圾清理

扫描临时文件、浏览器缓存、开发工具缓存、崩溃转储等位置，把勾选的文件移入回收站，也可以清空回收站。

## 使用

- 命令：在启动框搜索“垃圾清理”打开。
- 扫描范围：用户临时文件夹（`%TEMP%`；`C:\Windows\Temp` 属于系统目录，客户端不允许插件清理其中的文件，因此不扫描）；资源管理器缩略图与图标缓存；Edge、Chrome 的网页、脚本和 GPU 缓存（不含 Cookie 和已保存的密码）；npm、pip 缓存；VS Code 缓存与日志；应用崩溃转储和 Windows 错误报告；D3DSCache、SquirrelTemp；WPS Office 备份文件夹；“下载”文件夹里的安装包和压缩包（exe、msi、msix、zip、7z、rar、iso）。
- 默认勾选有内容的“安全缓存”类；WPS Office 备份文件夹（可能有文档备份）、npm / pip 缓存和“下载”里的安装包默认不勾选。顶部下拉框可按安全等级筛选，左侧可按类别筛选或切换到“样本文件明细”逐个勾选文件。
- Enter：清理当前筛选范围内已勾选的文件，确认框按项目列出文件数和大小；Ctrl+Enter：在资源管理器中定位；Ctrl+K：打开动作面板，可清空回收站、复制路径。
- 每类只把扫描到的最大 25 个文件作为样本，列表里写明可清理的样本数和大小；清理时只把勾选的样本文件移入回收站，不会清空整个文件夹，实际释放的空间通常小于列表显示的占用。文件在回收站里时仍占用磁盘空间，清空回收站后才会释放。
- 清空回收站需确认，会永久删除回收站里的全部文件（包括以前删除的其它文件），不能撤销；没能清空时提示原因。
- 正被占用或没有权限的文件会清理失败；只要有文件失败，提示里就会给出失败的数量和原因。读取不到用户目录时提示扫描失败。

## 平台与要求

- 支持：仅 Windows

## 网络与数据

- 不联网，数据只保存在本机。
