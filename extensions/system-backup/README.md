# 系统备份

把 Hosts、SSH 配置、Git 与 npm 全局配置、PowerShell 7 启动脚本、Windows Terminal 设置和 VS Code 设置打包为本地 ZIP 快照。

## 使用

- 打开后只列出本机存在的配置文件，默认全部勾选；不包含 PATH 环境变量或 SSH 私钥。取消不需要的项，按 Enter 创建已勾选配置的快照。
- 快照保存在文档目录下的 `ZToolsBackups`。每个配置来源放在独立目录中；同名的 `settings.json` 可以同时保存。归档内的来源清单记录原路径与条目位置。
- 如有文件无法读取，结果会显示实际备份数量和逐项失败原因。部分完成时仍保留已成功创建的归档；全部失败则不生成快照。
- 选中历史快照按 Enter 解压，或使用“解压最新快照”。最新快照按文件的实际修改时间选择。
- 每次解压都会创建新的输出目录，结果显示完整路径，并提供“打开解压目录”动作。解压不修改原配置；按需从输出目录取回文件。旧归档若包含重复文件条目会明确报错，保留已解压内容供检查。
- Ctrl+Enter 在资源管理器中显示所选文件，Ctrl+K 打开动作面板。

## 平台与数据

仅支持 Windows。全程离线，配置内容及来源路径只写入本机归档。
