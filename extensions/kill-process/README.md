# 结束进程

按内存或 CPU 占用列出正在运行的进程，确认后可结束单个进程或整个进程树。

## 使用

- 命令：结束进程。
- 列表显示进程名、PID、内存、CPU 和线程数（客户端读不到的项不显示），每 2 秒自动刷新（可在顶部暂停），读取失败时顶部状态条会显示原因；搜索框可按进程名、PID 或程序路径过滤，旁边的下拉框按内存、CPU、名称或 PID 排序。
- `Enter` 结束进程，`Ctrl+Enter` 强制结束，`Ctrl+Shift+Backspace` 结束整个进程树，`Ctrl+D` 查看详情（程序路径、启动命令行），`Ctrl+O` 在资源管理器中定位程序，`Ctrl+C` 复制 PID，`Ctrl+Shift+C` 复制程序路径（读不到程序路径时没有定位和复制路径这两个动作），`Ctrl+R` 刷新，`Ctrl+K` 打开动作面板。
- 每次结束前都会弹出确认框。“结束进程”会请求程序正常退出，程序可能弹出保存提示或拒绝关闭，这时可改用强制结束；强制结束和结束进程树会丢失进程里未保存的内容。csrss.exe、explorer.exe、svchost.exe、winlogon.exe、lsass.exe、dwm.exe 等系统关键进程不能结束。
- 结束前会核对进程名，PID 已经换成别的进程时不会执行；结束失败（例如权限不足、程序拒绝关闭）时会提示原因。

## 平台与要求

- 支持：仅 Windows

## 网络与数据

- 不联网，数据只保存在本机。
