# 批量重命名

选择或拖入文件 / 文件夹，按规则批量修改文件名；执行前逐个预览原名和新名，执行后可在本窗口内撤销。

## 使用

- 命令：在启动框搜索“批量重命名”打开。
- 导入文件：点击顶栏或动作面板的「选择文件」「选择文件夹」，或直接将文件 / 文件夹拖入、粘贴到窗口中。支持多次追加并按路径去重，新导入文件默认勾选。选择或拖入文件夹时仅导入第一层直接子文件，不进入子文件夹，跳过以 `.` 开头的隐藏文件和 `desktop.ini`、`Thumbs.db`、`Icon\r` 等系统元数据文件，单次最多导入 500 个。
- 左侧选择规则：追加序号（`_01`、中文数字、罗马数字，按列表顺序编号）、加前缀、加当天日期前缀（`YYYYMMDD_`）、在扩展名前加后缀、删除前 3 个字符、去掉 `()`、`[]`、`【】` 及其中内容（同时把空格换成下划线）、空格与连字符改为下划线并转小写、全部转小写。前缀和后缀取搜索框里的文字，搜索框为空时不改名，状态栏会提示输入。
- 在搜索框输入“旧词->新词”直接查找替换（只改文件名，不改扩展名；macOS 上分解写法的文件名，如日文浊音、带声调字母，也能匹配）；其他规则下，搜索框用来筛选文件名。
- 快捷键与动作面板：`Enter` 对已勾选文件执行改名（执行前弹出确认）；`⌘/Ctrl+Enter` 在资源管理器（macOS 为访达）中显示文件；`⌘/Ctrl+K` 打开动作面板，支持只改名当前文件（不再确认）、撤销上一次改名、从列表移除（`⌘/Ctrl+Backspace`，不删除磁盘文件）、全选 / 取消全选（`⌘/Ctrl+A`）与清空列表（`⌘/Ctrl+Shift+Backspace`，不删除磁盘文件）。
- 同名冲突按所在目录独立检测：新名与同目录内已有的直接子项重名（不区分大小写，也不区分 Unicode 组合与分解写法）、同目录内多个文件改成同一个名字，或新名不合法（Windows 另外不允许 `<>"|?*`、结尾的点或空格和 CON、NUL 等保留名）时，该项标为“同名冲突”且不会执行；不同目录下的同名文件互不冲突；改名不会覆盖任何已有文件。
- 权限说明：通过「选择文件夹」导入的文件夹直接拥有写授权；通过「选择文件」或拖入 / 粘贴添加的条目为「只读预览」，执行改名前会按所在目录逐个弹出文件夹授权框，必须选中对应原目录才会执行改名，取消或选错目录会保持只读预览并不改动对应文件。
- 撤销只针对本次打开插件后最近一次改名。

## 平台与要求

- 支持：Windows、macOS
- 需要客户端 1.1.8.3 或更新。

## 网络与数据

- 不联网，数据只保存在本机。
