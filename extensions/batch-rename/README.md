# 批量重命名

按规则批量修改一个文件夹里的文件名，执行前逐个预览原名和新名，执行后可以撤销。

## 使用

- 命令：在启动框搜索“批量重命名”打开。
- 顶部下拉框选择文件夹：下载、桌面、文档、图片、视频；点状态栏的“选择文件夹”可以换成其他文件夹。只处理文件夹第一层的文件，不进入子文件夹，跳过以 `.` 开头的隐藏文件和 desktop.ini、Thumbs.db，一次最多列出 500 个。文件默认全部勾选。
- 左侧选择规则：追加序号（`_01`、中文数字、罗马数字，按文件名顺序编号）、加前缀、加当天日期前缀（`YYYYMMDD_`）、在扩展名前加后缀、删除前 3 个字符、去掉 `()`、`[]`、`【】` 及其中内容（同时把空格换成下划线）、空格与连字符改为下划线并转小写、全部转小写。前缀和后缀取搜索框里的文字，搜索框为空时不改名，状态栏会提示输入。
- 在搜索框输入“旧词->新词”直接查找替换（只改文件名，不改扩展名）；其他规则下，搜索框用来筛选文件名。
- Enter：对勾选的文件执行改名，执行前会确认要改的数量并给出示例；⌘/Ctrl+Enter：在资源管理器（macOS 为访达）中显示文件；⌘/Ctrl+K：打开动作面板，可只改名当前文件（不再确认）、撤销上一次改名。
- 新名与文件夹里已有的文件重名、多个文件改成同一个名字或新名不合法时，该项标为“同名冲突”且不会执行；改名不会覆盖任何已有文件。
- 当前文件夹还没有授权时，执行改名前会弹出系统的选择文件夹窗口，选中该文件夹（或它的上级文件夹）授权后才会执行；选了别的文件夹会切换过去，需重新确认预览。通过“选择文件夹”打开的文件夹已经授权。
- 撤销只针对本次打开插件后最近一次改名。

## 平台与要求

- 支持：Windows、macOS
- 需要客户端 1.1.8.3 或更新。

## 网络与数据

- 不联网，数据只保存在本机。
