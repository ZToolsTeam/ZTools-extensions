# 音频转换

支持选择文件、选择文件夹或直接拖入音频文件，把勾选的音频用本机 ffmpeg 转换为所选格式。

## 使用

- 命令：在启动框搜索“音频转换”打开。
- 通过顶部「选择文件」「选择文件夹」或拖入音频/文件夹导入，支持 mp3、flac、wav、aac、m4a、ogg、wma、opus、aiff 格式（文件夹最多读取 5 层、单次最多 500 首）。
- 在右侧“输出格式”中选择 MP3、FLAC、WAV、AAC、M4A 或 OGG。转换使用 ffmpeg 的默认编码参数，选项里标注的码率、压缩级别（如 320k、Level 8）不生效。
- 合并模式（`BatchMergeAudio`）单次最多支持 100 个文件且总大小不超过 2 GiB。
- `Enter`：确认后转换全部勾选的文件；`Ctrl+Enter`：在资源管理器中定位文件；`Ctrl+O`：选择文件、`Ctrl+Shift+O`：选择文件夹；`Ctrl+Backspace`：从列表移除、`Ctrl+Shift+Backspace`：清空列表（不碰磁盘文件）；`Ctrl+K`：打开动作面板，可只处理当前文件。
- 输出文件名为 `<原文件名>_processed.<格式>`，保存在源文件所在文件夹；原文件不改动。已存在的同名输出文件会被覆盖，转换失败时会被删除。
- 目前只做格式转换：顶部下拉框里的处理模式（响度标准化、音量增益、静音切除、去头去尾、淡入淡出、均衡器、动态压缩、降噪、合并、写入标签），以及音质档位、响度标准、采样率、首尾静音切除、频谱降噪等设置都不生效；选“合并”时也是逐个文件单独转换。
- 需要自行安装 ffmpeg，并能在命令行直接运行；找不到 ffmpeg 时提示“本机未检测到 ffmpeg”。单个文件转换超过 60 秒会中止并报错。

## 平台与要求

- 支持：仅 Windows

## 网络与数据

- 不联网，数据只保存在本机。
