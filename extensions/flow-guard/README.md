# 流量监控

查看本机各进程的 TCP / UDP 连接和监听端口，按公网、局域网、本机回环分类，可强制结束正在联网的进程。

## 使用

- 命令：流量监控。
- 列表显示进程名、PID、本地与远端地址端口和连接状态；搜索框可按进程名、PID、程序路径、端口或 IP 过滤，旁边的下拉框可切换全部连接、仅公网、局域网、监听端口、仅 TCP、仅 UDP 和按进程聚合。连接明细最多显示前 120 条。
- 只显示连接情况，不显示网速和流量，也不能限速。列表在打开时读取一次，之后需要手动刷新；读取失败时顶部状态条会显示原因。
- 连接明细：`Enter` 强制结束该进程，`Ctrl+Enter` 复制这条连接的信息（也可按 `Ctrl+C`），`Ctrl+O` 在资源管理器中定位程序（读不到程序路径时没有这个动作），`Ctrl+R` 刷新，`Ctrl+K` 打开动作面板（只看该进程的连接等）。按进程聚合时：`Enter` 查看该进程的全部连接，`Ctrl+Enter` 强制结束该进程。
- “强制结束”会结束整个联网进程，而不是只断开某一条连接，进程里未保存的内容会丢失，执行前需要确认；插件不会阻止程序再次联网，程序重新打开或自动重启后会照常联网。System、svchost.exe、lsass.exe、dns.exe、csrss.exe、services.exe 等系统进程不能结束。结束失败（例如权限不足）时会提示原因。

## 平台与要求

- 支持：仅 Windows

## 网络与数据

- 不联网，只读取本机的连接与端口列表。
