# 防休眠常亮

在设定的时长内阻止系统自动休眠，可以选择同时保持屏幕常亮。

## 使用

- 命令：在启动框输入“防休眠”“常亮”或“caffeine”打开时长列表；输入“切换防休眠”打开插件并直接切换开 / 关，开启时为无限期、“保持屏幕常亮 + 防系统休眠”模式。关键词“开启防休眠”“关闭防休眠”也是切换，不是固定开启或关闭。
- 时长可选无限期（直到手动停止）、15 分钟、30 分钟、1 小时、2 小时、4 小时，选中后按 Enter 开启。
- 顶部下拉框选择模式：“保持屏幕常亮 + 防系统休眠”或“允许息屏，仅保持系统运行”。切换模式不影响正在进行的防休眠，下次开启时生效。
- 开启后状态栏显示剩余时间，在生效中的那一档按回车（“停止防休眠”）可以提前结束；搜索把它过滤掉时状态栏会出现“停止防休眠”；读取不到状态时显示原因和“重试查询”。
- 到期、手动停止、插件所在窗口被关闭、插件被停用或卸载、退出客户端时释放防休眠请求，系统恢复按原有电源设置运行；不会阻止手动锁屏和合盖休眠。

## 平台与要求

- 支持：Windows、macOS
- 需要客户端 1.1.8.5 或更新。

## 网络与数据

- 不联网，不保存数据。
