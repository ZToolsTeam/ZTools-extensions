# 局域网扫描

打开“局域网扫描”后选择网卡，结果列出本次有响应的设备及本机。Enter 复制 IP，⌘/Ctrl+Enter 查看端口与探测详情，更多动作可打开 Web 服务或收藏 MAC。

每次扫描所选网卡网段内最多 256 个 IPv4 地址。大于 /24 的网段可通过“选择范围”输入同一网段中的地址分段检查；小网段按实际掩码计算，不跨网段。扫描时可点“停止扫描”。

探测包括 ICMP 和 TCP 22、80、443、445、3389、5900、8080、8443。防火墙、休眠、无线客户端隔离会导致漏检；没有响应不代表设备不存在，也不代表其他端口未开放。MAC 由系统 ARP 缓存补充，缓存记录本身不算在线证据。TCP 响应耗时不等同于 ping 延迟。

macOS 27 为读取网络拓扑增加了专门的应用签名能力；未具备该能力的客户端可能得到空的邻居表，即使终端能看到 MAC。此时界面会明确提示，扫描到的 IP 和端口仍可使用，WOL 可手动输入 MAC。[Apple 开发者说明](https://developer.apple.com/forums/thread/822025?page=2)。

“远程开机”命令可直接输入或选择收藏的 MAC，无需先发现在线设备。发送目标是所选网卡的实际广播地址，UDP 端口为 9。目标设备须启用 Wake-on-LAN，且网络支持广播转发；成功提示只证明系统已发送 102 字节魔术包，不保证设备开机。收藏仅保存在本地，读取失败不会覆盖旧记录。

Windows 使用系统自带的 ping 与 ARP 表：只有收到目标本身带 TTL 的回复才算 ICMP 在线，网关代发的“无法访问目标主机”不算；Windows 收到已关闭端口的 TCP 拒绝后会重试，拒绝回应可能超出单个端口 350 毫秒的等待时间，因此不回应 ping 且所测端口均未开放的设备更容易漏检。

## 平台与要求

- 支持：Windows、macOS
- 需要客户端 1.1.8.5 或更新。
- Windows 实现尚待真机复核。

## 网络与数据

- 只在所选网卡的局域网网段内探测（ICMP 与上述 TCP 端口），唤醒包发往所选网卡的广播地址，不连接外部服务器。
- 收藏的 MAC 地址只保存在本机。
