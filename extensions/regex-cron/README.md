# 正则与Cron

常用正则速查与实时测试，以及 Cron 表达式解析。

## 使用

- 命令：常用正则 `常用正则`、`regex`；正则测试 `正则测试`、`regex test`；Cron `cron`、`crontab`、`cron翻译`。三个命令打开同一界面，可在顶部下拉框切换。
- 常用正则：身份证号、手机号、统一社会信用代码、车牌、固定电话、银行卡号、IPv4、端口号、邮箱共 9 条，附匹配与不匹配的示例。Enter 复制正则，⌘/Ctrl+Enter（或 ⌘/Ctrl+T）载入测试器，⌘/Ctrl+C 复制带斜杠和修饰符的写法。
- 正则测试：在搜索框输入正则（可写成 `/pattern/flags`，不写修饰符时默认 `g`），按 Enter 编辑待测文本，右侧列出每处命中及捕获组；⌘/Ctrl+Enter 复制正则。匹配超过 1 秒自动停止；正则最长 2000 字符，待测文本最长 50000 字符，最多显示 200 处命中。
- Cron：解析 5/6 位 Cron 并推算未来 5 次执行时间（本机时区，不支持 Quartz 编号及 L/W/#）。5 位为 Linux 语法（分 时 日 月 周），6 位为带秒的 Spring 语法。Enter 复制表达式，⌘/Ctrl+Enter 复制未来 5 次执行时间；下方有几条常用模板可直接推算。

## 平台与要求

- 支持：Windows、macOS

## 网络与数据

- 不联网，不保存数据。
