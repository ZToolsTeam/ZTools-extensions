# C盘搬家

把 C 盘用户目录下占用较大的文件夹（微信与 QQ 文件、下载、文档、视频、开发缓存）复制到其他分区，并在原位置建立目录联接（Junction），软件仍按原路径访问。

## 使用

- 命令：C盘搬家。
- 打开后扫描：文档下的 WeChat Files、xwechat_files、Tencent Files，下载、文档、视频文件夹，npm、pip、NuGet 缓存；只列出 C 盘上存在的目录。
- 搜索框旁的下拉框选择目标位置：C 盘以外每个分区的 `<盘符>\ZToolsMoved`。
- 目录默认不勾选，只迁移勾选的目录；互相包含的目录（如“文档”和其中的 WeChat Files）不能同时勾选，所选目录超过目标分区可用空间时不能迁移。
- 右侧目录上：`Enter` 迁移已勾选目录，`Ctrl+Enter` 在资源管理器中显示，`Ctrl+K` 打开动作面板（勾选或取消勾选）。左侧分类只用来筛选。
- 迁移前会列出要迁移的目录请你确认，确认后在弹出的窗口里选择目标分区（如 `D:\`）授权。目标位置已有同名文件夹或文件、或原位置已经是目录联接时跳过该目录，不会合并或覆盖。
- 迁移时先复制到目标位置，再把原目录改名备份并建立联接，成功后删除备份。复制后文件的修改时间会变成复制时的时间。
- 某个目录迁移失败时立即停止，其余目录不再执行。确认原目录完好时，删除这次复制到目标位置的文件；无法确认时不删除，提示你手动检查。原目录旁如果留有名称带 `.ztools-mover-bak-` 的文件夹，那是迁移中断时留下的原数据备份。
- 插件里没有迁回功能。迁移前请先退出相关程序（如微信、QQ）。

## 平台与要求

- 支持：仅 Windows

## 网络与数据

- 不联网，数据只保存在本机。
