# 视频转码

开发中，暂不在插件市场提供：客户端的视频处理接口单个文件最多运行 60 秒（常见时长的视频转换会超时失败），只按输出扩展名使用 ffmpeg 默认参数（不能指定画质、分辨率、码率），并且要求用户自行安装 ffmpeg；等客户端提供可长时间运行、可取消、支持编码参数并自带 ffmpeg 的转码接口，并在 Windows 上实测通过后再发布。

批量把视频转为 MP4、MKV、MOV、WebM 或 GIF，或提取音轨为 MP3、M4A、WAV。由本机已安装的 ffmpeg 按输出格式的默认参数处理。

## 使用

- 命令：视频转码（插件主命令）。
- 打开后扫描视频、下载、桌面目录，每个目录最多列出 40 个视频；搜索栏右侧选择任务（格式转换 / 转 GIF / 提取音频），左侧选择输出格式。不能设置画质、分辨率和码率。
- `Enter` 开始处理已勾选的视频（处理中变为「停止处理」，当前文件完成后停止）；`Ctrl+Enter` 在资源管理器中显示（处理成功后显示输出文件）；`Ctrl+K` 打开动作面板，可只处理当前文件、复制等效 ffmpeg 命令、复制输出文件路径。
- 单个文件处理超过 60 秒会被中止并提示失败，可复制等效 ffmpeg 命令到终端里运行。
- 结果另存为源文件同目录下的 `原名_ztools.扩展名`，同名文件已存在或无法确认时加序号或时间；不覆盖已有文件，也不修改原文件。
- 本机没有 ffmpeg，或命令行中不能直接运行 ffmpeg 时，处理会提示失败。
