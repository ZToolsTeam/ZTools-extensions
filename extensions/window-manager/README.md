# 窗口管理

把当前活动窗口贴靠到左右半屏、三分之一屏，或最大化、居中、按步长放大缩小。

## 使用

- 命令：窗口左右分屏贴靠与居中排版（关键词如 `窗口分屏`、`左半屏`、`窗口居中`）。另外两个命令（窗口置顶与透明度调节、活动窗口检索与切换）目前打开的也是这个分屏动作列表，暂不提供置顶、透明度调节和窗口切换。
- 选中动作按 `Enter` 执行；`Ctrl+Enter` 打开偏好设置；`Ctrl+K` 打开动作面板，可查看动作详情（`Ctrl+D`）、展开详情栏（`Ctrl+B`）、复制推荐快捷键（`Ctrl+C`）。
- 目前可执行的动作：左 / 右 / 上 / 下半屏，左 / 中 / 右三分之一，左 / 右三分之二，最大化，居中，合适尺寸，放大，缩小，恢复上一位置。列表中的其他动作（居中半屏、上 / 中 / 下三分之一、居中三分之二、四分之一、六分之一、几乎最大化、最大化高度或宽度、最小化、跨显示器等）客户端尚不支持，执行后窗口不会变化，也没有提示。
- 移动窗口要靠客户端的原生辅助组件完成；组件没有运行或移动失败时，同样没有提示。
- 偏好设置里的边距和"几乎最大化"比例目前不影响实际排版。
- 列表右侧的组合键只是推荐写法，可以复制，插件不会注册全局快捷键。

## 平台与要求

- 支持：仅 Windows

## 网络与数据

- 不联网，偏好设置保存在本机。
